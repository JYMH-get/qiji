- 用户说「收口本轮」「更新 CLAUDE.md」「把这轮记下来」「写变更记录」。

## 步骤

### 1. 确定当前轮次号（防并行撞号）

以 CLAUDE.md 头部「最后更新」为基准，再取**全文最大轮次号**双保险——并行会话可能已在 §8 写了更大的轮次但没动头部（第 229/230/231 轮实际撞过号；第 232 轮时头部还停在第 228 轮）。

本机 Git Bash：

```bash
cd /e/Kaifa/Qiji/qiji
grep -m1 -oE '最后更新：[0-9-]+（第[0-9]+轮' CLAUDE.md
grep -oE '第[0-9]+轮' CLAUDE.md | grep -oE '[0-9]+' | sort -n | tail -3
```

本机 PowerShell 5.1（⚠ 不支持 `&&`，用 `;` 分隔）：

```powershell
cd E:\Kaifa\Qiji\qiji; (Select-String -Path CLAUDE.md -Pattern '第(\d+)轮' -AllMatches).Matches | ForEach-Object { [int]$_.Groups[1].Value } | Sort-Object -Unique | Select-Object -Last 3
```

**本轮号 = 全文最大轮次号 + 1**（例：全文最大 234 → 本轮 235）。定号后复核该号未被占用（应输出 0）：

```bash
grep -c '第235轮' CLAUDE.md   # Git Bash；把 235 换成你定的号
```

### 2. 头部轮替

Read 前 80 行 → Edit 两处：

- 插入新行 `最后更新：YYYY-MM-DD（第N轮：**标题**——一段式浓缩：背景+改动要点+实测串+部署要求；详见 §8。）`（格式见 [references/format-examples.md](references/format-examples.md)）。
- 原「最后更新：」行整行**降级**为「上一轮：」（内容不动，只换前缀）。
- 若头部轮次 < 全文最大轮次（存在未收口的并行会话）：
  - 本轮负责统一收口 → 在新条目末尾注明收口范围（第 234 轮先例：`⚠ 本行收口第229-233轮并行会话的「最后更新待统一」：各轮完整记录均在 §8`）；
  - 本轮自己就是并行会话之一 → **不动头部**，只写 §8，并在条目末注明「头部『最后更新』待统一收口」（第 231/232 轮先例，防互相覆盖）。

### 3. §8 写全文条目

Grep 现查 `## 8. 变更记录` 行号（当前约 648 行，会漂移），新条目插在该标题正下方第一条（倒序排列）。格式固定：

```
- **YYYY-MM-DD 第N轮（标题 · 实测结论串 · 部署标注）**——背景一句 + ①②③ 逐点改动
  （⚠ 标注勿回退项及理由）+ 实测明细 + ⚠ **部署要求** + 已知边界/运营注意 + **待真机 QA**：…
```

真实完整范例（第 234 轮）见 [references/format-examples.md](references/format-examples.md)。措辞约定：改动引用文件用 `[文件名](相对路径)` 链接；实测数字如实写（54/54、602 vitest）；占位价、待填密钥等部署后动作明确列出。

### 4. 锁定规则同步抽进 §9A

本轮产生的「⚠ 勿回退/勿删/勿改」规则**逐条**抽进 `## 9A. 历轮锁定规则速查` 清单顶部（按轮次倒序），格式：

```

```

⚠ §8 里写了 ⚠ 而 §9A 漏抽 = 下轮改代码前查 §9A 查不到，规则等于没锁。
