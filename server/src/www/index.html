FEATURES · 功能介绍

三种模式，覆盖漫剧创作的全流程

从读剧本到导出成片，每一步都留在同一个工程里。

资产模式

剧本进去，整集的资产表出来

  • 剧本推理自动拆分集，理清人物关系与情节节奏
  • 提取角色 / 群像 / 场景 / 生物 / 物品五类资产，并生成出图提示词
  • 资产出图与造型变体，同一角色多套服化一次生成
  • 视频界面智能推理整集分镜：原文 + 故事板提示词 + 视频提示词，自动匹配垫图素材
分镜与剧本

分镜不再靠手敲

  • 整集分镜一次推理成表，原文与镜头一一对齐
  • 故事板提示词、视频提示词分开可编辑，改一句重生成一镜
  • 垫图素材自动匹配已生成资产，角色形象前后统一
画布模式

无限画布，想到哪连到哪

  • 8 类节点自由连线、流式裂变，一张图分叉出十个方向
  • 涂鸦标注直接改图，指哪改哪
  • 转深度图本地推理，零费用
  • 转视角、720° 全景、3D 导演台，镜头语言在画布上试
实时剪辑

剪映式时间轴，就在同一个窗口里

  • 多轨时间轴，AI 生成结果按分镜自动占位入轨
  • 成片回来原位替换，占位与成片顺序不会错乱
  • 一键导出剪映草稿，转到熟悉的工具里继续精修

常见问题

要自己准备模型 API 吗？

不用。生成走官方网关聚合的 20+ 渠道，按积分统一计费，模型热更新。

生成的素材存在哪里？

工程与素材保存在本地项目目录，可随项目一起打包迁移。

能接着用剪映精修吗？

可以。时间轴支持一键导出剪映草稿，轨道与分镜顺序保留。

有 macOS 版吗？

暂时没有，Windows 优先。macOS 版本在规划中。
