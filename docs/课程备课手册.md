# 灵创工场（Qiji）· 录课备课手册

> 本手册为**录制单元式教学视频**准备，分两部分：
> - **第一部分 · 客户端功能总清单**：按界面/场景分类的全量功能盘点（依源码逐界面核对），每项标注所属课程集数——录完对照打勾，保证无遗漏；
> - **第二部分 · 单元式课程大纲**：先一集速通全流程，之后**每集只解决一个问题**。每集给出目标、涉及功能、演示脚本与备课提示。
>
> 图例：⚙ = 该入口受服务商配置开关影响（录课前确认演示账号已全部开通）。

---

## 录课前的统一准备（一次性）

| 准备项 | 说明 |
|---|---|
| 演示账号 | 找服务商开一个**全功能账号**：资产+画布双模式、全部视频模式、共享素材库、LibTV/即梦入口全开，积分充足 |
| 演示小说 | 一部 2~3 万字的短篇（节奏快、角色 5~8 个、场景清晰），全程课程用同一部，学员有连续感 |
| 三个进度存档项目 | ①空项目（刚建好）②半成品（已拆分、资产已出图）③成品（某集已全部出片）——讲后期课程直接开对应存档，不用现场等生成 |
| 提前出好的素材 | 视频生成动辄几分钟：凡"点生成→等结果"的环节，提前生成好，录制时剪辑跳过等待 |
| 隐私打码清单 | 服务器地址、accessKey、激活码、机器码、兑换码——录屏时注意登录页与个人中心画面 |
| 每集口播模板 | 开场抛问题（10 秒）→ 演示解决（主体）→ 总结一句话 + 常见坑（30 秒）→ 下集预告（10 秒）。单集建议 **5~12 分钟**，速通集 30~40 分钟 |

# 第二部分 · 单元式课程大纲（共 13 单元 · 48 集）

> 命名规则：每集标题=一个问题。学员搜标题就能找到答案。

## 单元一 · 速通全流程（先走一遍）

### 第 1 集 · 从一部小说到成片（上）：建项目 → 拆剧本 → 出资产
- **目标**：学员建立全局地图，知道每一步在哪个界面发生。
- **涉及**：注册登录（一带而过）、新建项目+画风、剧集拆分（n-n 快拆）、资产拆分、五类资产页出主角/主场景。
- **脚本**：① 30 秒展示最终成片（先给结果）→ ② 建项目选画风 → ③ 粘贴小说、双拆分 → ④ 角色页出主角形象、场景页出主场景。
- **备课**：⚡空项目存档；只演示"最顺的路"，任何岔路口说"这里第 X 集详讲"；本集不解释原理。

### 第 2 集 · 从一部小说到成片（下）：分镜推理 → 出图 → 出片 → 导出
- **目标**：接上集跑完主线，学员对课程剩余部分有"目录感"。
- **涉及**:视频页智能推理、提取资产、生成故事板图、生成视频（带故事板首帧）、导出所有视频。
- **脚本**：① 智能推理整集 → ② 提取资产看垫图与图例 → ③ 逐镜出故事板图 → ④ 出视频（用提前生成好的结果剪辑）→ ⑤ 导出。
- **备课**：⚡半成品+成品存档各一；视频等待全部剪掉；结尾放全课程单元目录页。

## 单元二 · 账号与界面（每集一个问题）

### 第 3 集 · 注册时为什么绑定这台电脑？——账号、机器码与有效期
- **涉及**：注册/登录两页签、机器码复制、有效期四档、忘记密码流程、退出账号、设置→管理端（服务器地址）。
- **脚本**：注册演示 → 指出机器码在哪、什么时候要发给管理员 → 讲到期表现（能看不能生成）。
- **备课**：录屏打码激活码与机器码；准备一个"到期账号"截图讲现象。

### 第 4 集 · 表格和画布到底是不是两个软件？——界面总览与双模式
- **涉及**：大厅（搜索/侧栏/主题切换）、标题栏模式切换、左侧边栏七入口、停靠栏两助手、灯箱基本操作、位置恢复、表格布局记忆。
- **脚本**：同一项目表格↔画布来回切，指认"同一份数据"；双击图演示灯箱缩放。
- **备课**：⚡成品存档（画面丰富，切换效果直观）。

### 第 5 集 · 积分去哪了？——预估、退款、兑换码与请求记录
- **涉及**：个人中心概览（余额/当日/累计）、请求记录（筛选/展开/已退还）、兑换码、面板积分角标（预估=实扣）、余额不足拒单。
- **脚本**：生成一张图前后看余额 → 打开请求记录对账 → 演示一次失败退款记录 → 兑换码充值。
- **备课**：准备一条失败记录；强调"记录约保留 30 天"。

## 单元三 · 项目与剧本

### 第 6 集 · 画风为什么建项目时就要定？——新建项目详解
- **涉及**：项目名/封面/画风下拉、双模式入口、项目设置（改名换封面）、删除项目、视觉风格下拉。
- **脚本**：建两个项目选不同画风 → 出同一角色对比风格差异 → 演示改名换封面。
- **备课**：⚡两张不同画风的同角色图提前出好；口播强调"中途换画风=已出图全部风格不统一"。

### 第 7 集 · 四种快拆一种智能，剧集拆分怎么选？
- **涉及**：剧集拆分模板下拉全部选项（第N集标记/空行/n-1/n-n/LLM 模板）、分析模型选择。
- **脚本**：拿三段格式不同的文本各拆一次，展示结果差异 → 总结选择口诀（有标记用标记、有空行用空行、都没有用 LLM）。
- **备课**：准备三种格式的文本片段各 2000 字。

### 第 8 集 · 资产拆分拆出了什么？——五类资产与视觉圣经
- **涉及**：资产拆分+模板下拉、流式计数卡、五类分流（C/G/S/M/P 编号）、视觉圣经查看与编辑、继续提取/重新分析。
- **脚本**：点拆分看计数上涨 → 五个资产页走一遍看分流 → 改视觉圣经一处，讲它影响所有出图。

### 第 9 集 · 拆错了怎么办？——重拆规则与分集管理
- **涉及**：重拆覆盖确认弹窗、确认弹窗通用规则（Enter/Esc）、分集重命名/删除、上增/下增补分镜。
- **脚本**：故意重拆触发弹窗逐字读一遍 → 取消 → 演示改分集名、删空分集。
- **备课**：⚡用可牺牲的副本项目演示真覆盖一次，展示后果。

## 单元四 · 资产工坊

### 第 10 集 · 一张立得住的主角图是怎么出的？——基础形象工作流

### 第 11 集 · 战损、换装怎么保持是同一个人？——造型变体
- **涉及**：造型列表新建/一键生成、变体=图生图锁 DNA、造型右键（重命名/共享/删除）。

### 第 12 集 · 我有现成的设定图，怎么用？——本地图与资产替换

- **脚本**：上传设定图当形象 → 演示"用分体替换基础形象"场景 → 导出一张给外部修图再传回。

- **涉及**：匹配规则（5 字内全等/长名 80% 容错/别名与造型名参与）、更改分组、资产改名。
- **脚本**：造一对相似名演示误配与不配 → 用别名解决 → 总结命名三原则。

## 单元五 · 分镜工作台

### 第 17 集 · 镜头切分点不对，别重拆——上拆/下拆/上增/下增
- **涉及**：上拆下拆（按非空行迁移）、上增下增、删除分镜、原文分格右击编辑模式。

### 第 18 集 · 一键垫图——提取资产与素材图例

- **备课**：第 13/14 集的伏笔在这里收；⚡绑好音色的角色。

### 第 19 集 · 素材区的规矩：只往后加，不往前插
- **涉及**：分镜素材条（＋本地上传/双击放大/✕删除）、编号与 @ 引用联动、删素材图例自动同步。
- **脚本**：手动加一张参考图 → 删中间一张看编号前移、图例条目消失 → 讲"@ 引用永不错位"的原因。
- **备课**：本集是第 20 集 @ 引用的地基。

## 单元六 · 提示词系统

## 单元七 · 出图与出视频

### 第 24 集 · 故事板图的参数从哪来？——画质/比例/分辨率与历史回退
- **涉及**：视频设置「故事板·图像」三项、档位由模型下发、历史条回退、一键故事板。
- **脚本**：改比例 9:16 出一张 → 历史条来回切主图 → 一键故事板批量跑。
- **备课**：档位下拉"看到什么就是什么"由服务商配置，口播说明。

### 第 25 集 · 选视频模型的正确姿势：模式 → 模型 → 方法 → 要求
- **涉及**：四级选择、模型源折叠、方法下拉出现条件、时长/比例/分辨率收敛、真人图 chips ⚙、单镜覆盖 vs 全局默认。
- **脚本**：全局默认设一套 → 单独给第 5 镜换模型换时长 → 讲"档位自动收敛不怕选错"。
- **备课**：⚙确认演示账号开了多个视频模式，下拉才好看。

### 第 26 集 · 首尾帧：控制视频的第一帧和最后一帧
- **涉及**：方法=首尾帧、取帧规则（带故事板→故事板图为首帧；素材第 1/下一张图）、附带项（带资产/带故事板）、素材不足前置报错。
- **脚本**：素材区按序放两张图出片 → 对照首尾帧 → 演示不足两张的报错（不扣费）。
- **备课**：⚡首尾帧成片提前出好。

### 第 27 集 · 视频太慢？并行提交 + 断连重连
- **涉及**：一键视频（全部生成/奇数生成）、多镜并行、关软件重开自动重连、失败自动退款。
- **脚本**：一键提交 5 镜 → 当场关软件 → 重开看任务全部找回 → 讲"奇数生成"适合先看效果再补偶数。
- **备课**：这是最能建立信任感的一集，务必真演示关软件。

## 单元八 · 后处理与导出

### 第 28 集 · 超分和去字幕：处理的到底是哪个版本？
- **涉及**：右击超分/去字幕、派生记录标号（v2+ 青/v2- 橙）、"处理对象=当前选中记录"、链式处理与同标号覆盖。
- **脚本**：对 v1 超分得 v1+ → 选中 v1+ 去字幕 → 讲标号只看最后一次处理。
- **备课**：⚡处理结果提前生成；这是概念最绕的一集，画一张标号示意图备用。

### 第 29 集 · 值不值这个积分？——对比原图/原视频
- **涉及**：派生记录右键对比（滑杆分割/分辨率角标/双路同步播放）、画布处理节点面板的对比与重新处理。
- **脚本**：滑杆左右拉对比超分前后 → 视频双路同步拖进度条。
- **备课**：挑一个对比效果明显的素材。

### 第 30 集 · 镜头衔接生硬？首尾帧接力 + 片段垫料
- **涉及**：视频右键（添加首帧到上一镜/尾帧到下一镜/视频片段到下一镜…）、画布悬停截帧四钮、分段（本地免费）。
- **脚本**：把第 3 镜尾帧送第 4 镜当首帧重出 → 对比衔接前后。
- **备课**：⚡衔接前后两版视频。

### 第 31 集 · 图片不够清晰？图像超分
- **涉及**：故事板图右击图像超分、倍率/2K/4K 目标换算与上限夹紧、画布图片节点同入口。
- **脚本**：一张故事板 2K 超分 → 对比原图 → 讲上限自动夹紧不用算。
- **备课**：与 28 集区分：这是图片，那是视频。

### 第 32 集 · 交付：导出的所有姿势
- **涉及**：逐镜导出图片/视频、导出所有视频、画布节点保存到本地、文件菜单导出项目(.Qiji 可跨设备)、灯箱右击保存。
- **脚本**：导出所有视频进剪辑软件 → 顺带导出项目文件讲备份意义。
- **备课**：强调"云端直链有时效，本地留档最稳"。

## 单元九 · 画布入门

### 第 33 集 · 画布是什么：节点是步骤，连线是数据流
- **涉及**：8 类节点认知、右键空白建节点、单击开面板、连线语义（素材/文本进下游）、拖到空白生成上下游菜单、▤ 上游文本胶囊。
- **脚本**：手搭"文本→智能推理→图片"最小链 → 指认胶囊如何明示上游输入。
- **备课**：本集只搭链不深讲，节奏放慢。

### 第 34 集 · 表格做的东西怎么到画布？——同步与投影
- **涉及**：同步本集到画布（幂等/不动手建节点/资产不投影）、从资产助手拖资产进画布、图视同源切换后的链路变化。
- **脚本**：表格推理完 → 同步 → 看投影流水线 → 再改表格重新同步看增量。
- **备课**：解释"资产不投影是为了不卡"。

### 第 35 集 · 裂变：让流水线自己长出来
- **涉及**：运行推理/拆分节点流式裂变、分镜n原文→故事板→视频命名、原文节点自带重推（只补下游接自身）。
- **脚本**：跑一个分集节点看节点逐个蹦出 → 改某镜原文节点直接重跑。
- **备课**：裂变过程本身就是视觉高潮，别剪太碎。

### 第 36 集 · 画布不乱的四个开关 + 整理
- **涉及**：吸附/重叠/网格/小地图、整理（拼图式）、整理间距设置、拖动挤开让位、多画布与＋分集、本地素材库条。
- **脚本**：故意拖乱 → 一键整理 → 演示吸附参考线与挤开让位 → ＋分集新画布。
- **备课**：挤开与吸附用慢动作演示。

## 单元十 · 画布进阶

### 第 37 集 · 一个节点管理十版结果——堆叠
- **涉及**：C 键/右键开抽屉、双击灯箱、右击设主图、拖出 1 秒复制、拖入 1.5 秒并入、悬停「上传」把本地成品并入堆叠。
- **脚本**：重跑 3 版图全进堆叠 → 挑版设主图 → 把两个试验节点并成一叠。
- **备课**：⚡一个带多版结果的节点存档。

### 第 38 集 · 复制的三种姿势 + 和微信互通的剪贴板
- **涉及**：精准复制/全能复制（自动接回上游）/ALT 拖动（原位留替身）、复制图片节点=图进系统剪贴板、粘贴截图/文字进画布。
- **脚本**：三种复制各演一次看连线差异 → Ctrl+C 图片节点粘到微信 → 微信截图粘回画布。
- **备课**：互通演示极圈粉，留足镜头。

### 第 39 集 · 多选与批量：一次操作二十个节点
- **涉及**：框选、悬浮工具栏（全部启动/匹配素材/增加预设/检查素材/合并打组/合并为分镜组/删除）、批量连线（多选后从任一节点拉线）、框选连线删除、打组/解组。
- **脚本**：框选一排图片节点批量加预设并全部启动 → 5 节点一次连到合成节点。
- **备课**：Ctrl+Enter 全部启动是效率名场面。

### 第 40 集 · 拆分、重组与二次解析：不花钱的返工三件套
- **涉及**：原文节点右键拆分（按行）、多选重组文本、二次解析补缺漏（不扣费）。
- **脚本**：一镜拆成 1-1/1-2 各自推理 → 误删一个裂变节点用二次解析找回。
- **备课**：强调三个操作都免费且可撤销。

### 第 41 集 · 多图合一与一图拆多：分镜组与宫格切分
- **涉及**：合并为分镜组、宫格/比例/序号/拖格重排、拼接 2k/4k、解组、图片右键宫格切分。
- **脚本**：6 张分镜图合组 → 拖格调序 → 拼接 2k 大图 → 反向把一张 6 宫格故事板切开。
- **备课**：⚡一张 6 宫格图。

### 第 42 集 · 把画布调成你的手感：参数联动与快捷键
- **涉及**：同类节点参数联动（及不联动的字段）、设置→快捷键改绑（录制/冲突拦截/恢复默认）、整理间距、悬停工具栏全览。
- **脚本**：改一个图片节点分辨率看全画布跟随 → 把堆叠键 C 改成 X 立即生效。
- **备课**：口播提醒 Delete 改绑后输入框不误删。

## 单元十一 · 两个悬浮助手

### 第 43 集 · 资产助手：素材的中转站
- **涉及**：三页签（项目/收藏/共享）、六类 chips、☆收藏、右键选造型、音色试听、拖拽三去处（素材区/画布/软件外）、检查所有资产入口。
- **脚本**：收藏常用资产 → 分别拖到素材区、画布、桌面 → 右键换造型。
- **备课**：拖到软件外=复制文件，很多人不知道。

### 第 44 集 · 简一助手：软件里的 AI 军师
- **涉及**：多会话管理、分身多开、文本模型选择、上传图片/文件（Word/文本/字幕/代码）、粘贴截图、消息复制/重新回答/回退。
- **脚本**：开两个分身分别讨论剧情与提示词 → 粘贴分镜截图让它点评 → 回退重问。
- **备课**：定位讲清：它是顾问，不直接改项目数据。

## 单元十二 · 协作与外部渠道

### 第 45 集 · 团队怎么共用一套角色？——共享素材库 ⚙
- **涉及**：搜索加入（密码）、三级导航、获取/更新、分享（右键四入口/批量）、添加到项目资产/绑定音色、分类过滤、位置记忆、退出库。
- **脚本**：以"新成员"视角加入库 → 获取 → 把主角绑进自己项目 → 再以"提供者"视角分享一个新造型。
- **备课**：⚡提前建好演示库并放入素材；强调分享是登记不是上传。

### 第 46 集 · 用自己的即梦/LibTV 会员出片 ⚙
- **涉及**：两渠道授权流程、模型下拉注入、款式与参数档、手续费说明、排队与重连原任务、CLI 登录态复用。
- **脚本**：授权即梦 → 用它出一片 → 讲排队慢是常态与重连按钮。
- **备课**：即梦排队不可控，成片务必提前生成。

## 单元十三 · 维护与排障

### 第 47 集 · 数据不丢的五道保险
- **涉及**：自动保存/.bak、关闭窗口确认、提交历史回滚、导入导出项目、存储目录更改、WebDAV 云同步、检查素材（死链自愈/异常名单）、机器码换机流程。
- **脚本**：看提交历史回滚一次 → 跑一次检查所有资产读报告 → 配一个 WebDAV。
- **备课**：本集是"售后信任"集，语气笃定。

### 第 48 集 · 报错对照与省积分清单（完结）
- **涉及**：常见提示对照（额度不足/服务暂不可用/账号已到期/模型未开放/垫图无法获取/无 OSS 记录/机器码不符/详情报文已清除/无可用模型→查管理端连接）、免费操作清单（截帧/分段/拼接/切分/二次解析/检查/导出）、重跑前先走便宜路。
- **脚本**：逐条报错讲"什么原因→找谁→怎么办" → 省积分清单快闪总结 → 全课程回顾。
- **备课**：对照《用户教程（实战版）》附录 B，注意"未配置模型"一条已更新为检查管理端连接。
