## 一、先养成的使用习惯

**1｜随时可以关软件。** 出图、推理、视频生成进行到一半退出都没关系：任务在云端继续跑，重新打开项目会自动重连原任务等结果，**不会重复扣费**。视频这种十几分钟的长任务，提交完就可以去干别的。

**2｜重开自动回到上次的位置。** 软件记住你上次所在的页面、分集、滚动位置，打开项目即恢复现场，不用自己找回进度。

**3｜模型基本不用配置。** 没有手动选过模型时，软件自动使用该能力下第一个可用模型；在任意下拉里选过一次，选择会记在**当前项目**里。服务商上新模型、调价格、改档位后 **30 秒内自动生效**，无需重启软件。

**4｜看到「无可用模型」提示，问题一般不在模型。** 先到 设置 → 管理端 检查服务器连接是否正常，目录拉取成功后模型列表会自动回来。

**5｜快捷键全部可改绑。** 设置 → 快捷键：点键位胶囊进入录制模式按下新键即可，冲突会被拦截并提示占用方；支持单项或全部恢复默认。小细节：把 Delete 改绑成字母键后，在输入框里打字不会误删节点（自动让位）。

**6｜画布「整理」的行间距可以调。** 同在 设置 → 快捷键 页的「画布整理」区块，0~400px 自由设置（默认 48）。喜欢紧凑或宽松排版的都能调到顺手。

**7｜表格的列宽、行高会全局记忆。** 按自己的屏幕拖一次，之后所有项目都沿用。

**8｜简一助手支持直接粘贴截图。** 微信/QQ 截图后在简一助手窗口直接 Ctrl+V，图片自动变成待发送的垫图；助手还支持多会话与分身，不同话题分开聊互不干扰。

## 二、提示词与胶囊技巧

**9｜@ 引用 + 数字快选。** 提示词里输入 `@` 弹出素材候选框后，直接按 **1~9** 选中对应素材插入，不用鼠标点。`@Image1 / @Video1 / @Audio1` 分别引用素材区第 N 个图 / 视频 / 音频。

**10｜预设胶囊（▦）一键插入整段预设词。** 图片节点面板功能栏、表格单卡提示词顶部都有「▦ 预设方案」入口。插入的是一枚胶囊，**提交时才展开**成完整预设正文，平时不占提示词版面。

**11｜双击预设胶囊 = 就地展开成可编辑文字。** 想在预设基础上微调时，双击胶囊即变为普通文本，随意修改。

**12｜自定义你自己的预设。** 设置 → 预设方案：填名称和正文即可新增；还能设置——
- **互斥组**：同组预设只留一个（比如填「宫格」，插入你的预设会自动替换掉已有的 4/6/9 宫格预设）；
- **位置**：前缀预设自动落在你输入的正文之前，后缀预设落在最后。

**13｜宫格预设 4/6/9 互相替换。** 内置三档宫格故事板预设是同一互斥组：插 4 宫格会自动移走 6/9 宫格，不会叠加冲突。

**14｜胶囊位置可以拖。** 预设胶囊、上游文本胶囊都支持按住拖动到提示词任意位置，自动落位不合心意就手动摆。

**15｜画布的「隐形输入」全部明示。** 给节点连上游文本节点后，提示词框自动出现青色「▤ 上游文本N」胶囊——提交时还原为上游节点的实际文本。看到胶囊就知道这个节点会吃到什么输入，断开连线胶囊自动消失。

**16｜放大编辑弹窗里藏着批量替换。** 提示词点「放大」进入大屏编辑，顶栏打开「**替换**」：输入查找内容实时显示命中数并**黄色高亮**所有将替换处，替换为留空即批量删除，输入框内按 Enter 直接执行。角色改名、批量删除口头禅一步到位。

**17｜放大弹窗默认保存退出。** 点遮罩、点 X、按 Esc 都会**保存后关闭**，只有「取消」按钮才丢弃修改——长文编辑不怕误触丢稿。

**18｜放大弹窗顶栏可以直接「匹配资产」。** 以当前草稿为准执行完整匹配（含音色配对与图例刷新），改完提示词不用先保存再回外面点匹配。

## 三、素材与资产匹配技巧

**19｜资产命名决定匹配成功率。** 匹配按名称进行：**5 字以内的短名必须完全一致**，更长的名称允许约 2 成的书写出入（空格、标点、全半角差异会被自动忽略）。技巧：
- 资产名之间**别太相似**（「林凡」和「林帆」很难区分时，用别名区分）；
- 别名、造型名同样参与匹配，多起几个常用叫法命中率更高。

**20｜先在资产助手选定造型，再提取资产。** 资产助手里右击卡片选中某个造型（如战损造型），之后「提取资产 / 匹配素材」垫进分镜的就是这个造型，不用逐镜手动换图。

**21｜角色绑了音色，声音自动跟人走。** 匹配到该角色时音频自动进素材区，图例自动写「@ImageN的声音参考@AudioM」。资产助手卡片右下角的音频圆标可**点击试听**；双击放大的灯箱底部也有播放条。

**22｜素材顺序规则：只往后加、不往前插。** 素材区编号按加入时间排定，先匹配再连上游、后补素材都不会让已有 @ 引用错位，放心随时增补。

**23｜删素材不用手改提示词。** 删除素材时图例对应条目自动消失、后续 @ 编号自动前移；上游连线带来的素材也能删——悬停 ✕ 或右击删除即**断开对应连线**。

**24｜垫图报错会指名道姓。** 「垫图无法获取：第 N 张「xx」」说明那张图的云端链接失效——对该素材跑一次「检查素材」（本机有副本会自动修复），或重新上传该图。

**25｜定期「检查素材」。** 三处入口：画布节点右击、资产/造型右击、资产界面右上角与资产助手标题栏的「检查所有资产」。死链且本机有本地副本的会**自动重传修复**，报告里「无 OSS 记录（异常）」的素材建议重新生成或重新上传使其入库。

**26｜散图也能归档成资产。** 画布上任何有图片结果的节点右击「**绑定到资产…**」：五类页签选现有资产（双击卡片直接绑）或输入名字新建；音频节点右击可绑为任意资产的**音色**。临时试出来的好图别浪费，绑进资产库就能参与匹配。

## 四、表格模式提效技巧

**27｜三种推理按需选。** 智能推理=整集出全套（原文+双提示词+时长）；智能拆分=只拆原文不写提示词（想全手写时用）；单镜推理=只重跑某一镜。还有「一键推理所有单镜」逐镜批量跑。

**28｜单镜推理自动带邻镜上下文。** 上一镜 / 下一镜的内容（优先取已推理的结果）会随单发送保证连贯。技巧：**逐镜精修时从前往后推**，每一镜都能参考到上一镜的最新成品。

**29｜上拆 / 下拆按非空行迁移。** 分镜原文的首行/末行会移入相邻分镜，空行不算分格也不外显。镜头切分点不对时用它微调，不必重新拆分。

**30｜图视同源 = 一段提示词管图和视频。** 视频设置里开启后提示词区变单栏，改一处两边生效。附赠：生成故事板图时按提示词里的镜头数**自动追加 4/6/9 宫格预设**（已手写宫格指令则不重复加；推理出结果后才生效）。

**31｜故事板图右击有三宝。** 导出、**图像超分**（倍率或 2K/4K 目标）、首尾帧送相邻镜。

**32｜镜头衔接靠首尾帧。** 上一镜视频右击把**尾帧**送给下一镜当首帧参考，画面过渡立刻自然；「视频片段到下一镜」可把上镜结尾片段直接垫给下一镜。

**33｜超分 / 去字幕的处理对象 = 当前选中的记录。** 历史条选中哪个版本，处理的就是哪个版本（可链式：先超分再去字幕，处理的是超分版）。派生记录标号规则：`v2+` = 超分（青色）、`v2-` = 去字幕（橙色），只看**最后一次**处理；同标号后来的覆盖前面的。

**34｜右击派生记录可「对比原视频」。** 全屏滑杆分割对比，双路同步播放拖动进度条两侧同跳；图像超分同理可对比原图（带两侧分辨率角标）。效果值不值这个积分，对比一眼便知。

## 五、画布模式提效技巧

**35｜堆叠抽屉是画布的版本管理器。** 有结果的图片/视频节点按 **C** 或右击「打开堆叠」：双击卡片=灯箱放大，右击=设为主图，**拖出面板悬停 1 秒**=复制成独立节点（原记录保留）。多版结果全在一个节点里，画布不乱。

**36｜把同类节点拖上去 1.5 秒 = 并入堆叠。** 图片对图片、视频对视频，拖到目标节点上悬停约 1.5 秒出现绿框提示后松手，两个节点合并为一叠（可一次撤销恢复）。多方案收拢神器。

**37｜复制有三种姿势，按需选用：**
- **Ctrl+C**（精准复制）：只带选中节点与它们之间的连线；
- **Ctrl+Shift+C / 右键「全能复制」**：粘贴时若原上游节点还在画布上，**自动把上游连线接回**；
- **ALT+拖动**：原位留下一个完整替身（上下游连线都在），拖走的是只带上游连线的副本。堆叠节点 ALT 拖动时，拖走的只带主图、完整历史留在原地。

**38｜复制图片节点 = 顺带复制图片本身。** Ctrl+C / 全能复制后，选中集中第一个有图节点的主图会写入**系统剪贴板**（PNG），可直接粘贴到微信、PS、简一助手等任何地方。

**39｜系统剪贴板可以直接贴进画布。** 截图 Ctrl+V → 自动生成上传节点并传云端；纯文字 → 生成文本节点。外部素材入库就是一次粘贴的事。

**40｜多选后从任一节点拉线 = 批量连线。** 选中 5 个节点从其中一个拉到目标，5 条边一次成型（自动跳过重复、成环、格式不兼容的）。

**41｜连线也能框选和右击直删。** 在**不含节点的空白区**框选可选中一批连线，Delete 一键删除；单条连线右击直接删除，无需二次确认菜单。

**42｜原文节点可拆可合。** 右击「**拆分…**」按行设置拆分点，一镜拆成 分镜1-1 / 1-2…（各自可独立推理）；多选多个原文节点右击「**重组文本**」按阅读序合并回一个节点。两个操作都是一次撤销可回退。

**43｜原文节点自己就能重推理。** 分镜原文节点就是智能推理节点：改完原文直接点运行，只会补出新的故事板/视频节点接到自己身上，旧节点自动避让保留，方便新旧对比。

**44｜「二次解析（补齐缺漏）」免费补节点。** 推理/拆分节点右击可对**已有结果文本**重新解析，只补建缺漏的子节点——**不重跑模型、不扣积分**、不动你已编辑过的节点。误删了裂变节点、流式中断少了行，都用它救。

**45｜同类型节点的设置自动联动。** 改一个图片节点的比例/分辨率/模型，同画布所有图片节点跟随（视频同理）；提示词、视频时长这类"内容"不联动。智能推理节点的模板选择也是全画布统一。要保证整集输出规格一致，改一处就够。

**46｜多选批量操作记得用。** 框选后悬浮工具栏 / 右键菜单提供：批量匹配素材、**一键增加预设**、一键检查素材、合并为分镜组。

**47｜分镜组节点把多图收成一张宫格。** 多选有图节点右键「合并为分镜组」：宫格 2×2~4×4 可切、**按住格子拖动重排**、可显示序号角标；「拼接」直接合成 2K/4K 大图（本地合成不扣积分）；「解组」再展开回独立节点。

**48｜一张宫格图可以反向切开。** 图片节点右击「**宫格切分…**」：选宫格规格、点选要切出的格子，逐格裁剪成分镜组。6 宫格故事板一键拆成 6 个分镜素材。

**49｜视频节点自带剪辑台。** 悬停工具栏可截**当前帧/首帧/尾帧/尾段**成图片节点；右击「**分段…**」选起止时间裁出片段（本地 ffmpeg，不扣积分）；超分/去字幕按钮也在悬停工具栏。

**50｜自己的成品图也能传进节点。** 图片/视频节点悬停「**上传**」可多选本地文件：最后一张成为主图，其余与旧结果一起进堆叠。外部精修后的图放回原节点，版本线不断。

**51｜三个画布开关按需切换。** 小地图旁：「**吸附**」= 拖动时青色参考线自动对齐（默认开）；「**重叠**」= 允许节点自由堆放（默认关，关闭时拖动压到别人会整枝让位、挤开的布局一次撤销可回）；「**网格**」= 点阵背景显隐。

**52｜大项目按分集用画布。** 每个分集是一块独立画布，分集选择器旁「**＋分集**」可直接新建。资产图不会自动投影进画布（防卡顿），需要哪张从资产助手**拖进来**即可。

**53｜画布节点右击「保存到本地」。** 媒体产物存为文件、文本结果存 .txt，不用打开灯箱再另存。

## 六、视频生成与后处理技巧

**54｜选模型按「模式 → 模型 → 方法 → 要求」四级走。** 模式=渠道源头，模型=具体款式，方法=全能参考/首尾帧（模型支持才显示），要求=时长/比例/分辨率（档位由所选模型决定，自动收敛不怕选错）。

**55｜「首尾帧」方法的取帧规则要记住。** 首帧 = 开了「带故事板」时的故事板图，否则取素材区第 1 张图；尾帧 = 下一张未用过的图。技巧：**素材区按序放两张图**即可精确控制首尾画面；素材不足两张会在提交前直接报错，不白扣费。

**56｜部分模型支持「真人图」。** 素材区图片按序号勾选后，对应垫图按官方真人参考通道发送（仅全能参考方法下显示入口）。

**57｜视频并行提交，别串行等。** 多个分镜依次点生成后台同时跑，关软件也不断；失败的自动退积分。串行等一镜出一镜是最大的时间浪费。

**58｜生成前看一眼积分角标。** 角标显示的预估**就是实扣**（按秒计费的模型 = 单价 × 时长）；余额不够会直接拒单，不会扣到一半失败。

**59｜接入即梦 / LibTV 用自己的账号出片。** 个人中心授权后，视频模型下拉出现对应渠道，消耗对方平台额度、软件侧只收少量手续费（实价见角标）。注意：**对方平台排队慢是常态**（尤其即梦免费队列），生成超时被打断后任务不丢，「重连原任务」继续等即可；终端里已登录过对方 CLI 的直接复用登录态。

**60｜超分档位、模型清单以界面为准。** 可用分辨率档、可用模型由服务商配置并热更新，下拉里看到什么就是什么；想要更高档位联系服务商开放。

## 七、省积分与账单技巧

**61｜这些操作全部免费（本地完成，不扣积分）：** 截帧（当前帧/首帧/尾帧/尾段）、视频分段、分镜组拼接 2K/4K、宫格切分、导出、二次解析、检查素材、堆叠管理、匹配素材。

**62｜重跑之前先把便宜的路走完。** 改提示词、换垫图、换造型都不花钱；历史图/历史视频全部保留，随时切回主图，不存在"覆盖了就没了"，大胆试。

**63｜失败必退款。** 任务失败自动退积分，请求记录里标「已退还」。发现余额不对先看请求记录，不用凭感觉猜。

**64｜请求记录就是你的账单。** 个人中心 → 请求记录：每条任务的时间、步骤、模型、扣分、状态，可按状态筛选、展开看提交内容与返回结果。**记录约保留 30 天**，需要长期对账请及时截图/记录。

**65｜大额视频消耗可以转移。** 有即梦/LibTV 会员额度的，把视频生成切到自己账号（见技巧 59），软件积分只出少量手续费。

## 八、团队协作与素材复用技巧

**66｜分享素材是"登记"不是"上传"。** 右击资产/造型/画布节点/资产助手卡片 →「添加到共享资产」，登记的是云端记录，**秒完成、不重复占空间**；画布节点可多选批量分享。

**67｜取用共享素材的两条路。** 轻用：把共享卡直接**拖**进分镜素材区/画布当垫图；正式用：右击 →「添加到项目资产…」绑进自己项目（图片绑形象、音频绑音色），之后走正常匹配流程。

**68｜「获取」只补新增。** 进入共享文件夹点「获取」下载素材到本地，再次获取只下载新增部分；文件夹列表进库自动刷新。软件会记住你上次浏览到哪个库哪个文件夹。

**69｜共享库素材自动按类分栏。** 角色/场景/生物/群像/道具/其他 分类筛选，按资产编号自动归类——上游分享时命名规范（带角色名），下游用起来才顺。

## 九、稳定性与数据安全技巧

**70｜项目文件有三重保护。** 原子写入 + 滚动备份（.bak）+ 损坏自动恢复；断电、崩溃后重开一般都能自愈。**不要手动编辑 project.Qiji 文件**。

**71｜机器码是硬件指纹。** 清除软件数据、重装软件都**不会**变码，不用担心误触发换机拦截；更换主板/系统盘或重装系统可能变码，届时联系服务商解绑后重新登录即可。

**72｜危险操作都有确认弹窗。** 重新拆分（覆盖 N 集 M 分镜）、各类删除都会弹应用内确认框：Enter=确定、Esc=取消。看清数字再按 Enter。

**73｜账号到期只锁生成、不锁数据。** 到期后仍可登录查看和导出项目，续期后原样继续。

**74｜长期项目养成两个体检习惯。** ① 定期「检查所有资产」（见技巧 25）；② 重要成片及时「导出」到本地留档——云端直链有时效，软件虽会自动转存，本地文件永远最稳。

## 十、避坑清单

| ⚠ 坑 | 后果 | 正确姿势 |
|---|---|---|
| 中途换项目画风 | 前后出图风格不统一 | 建项目前定稿画风；确要换则接受已出图需重跑 |
| 已做分镜后重新「剧集拆分」 | 覆盖全部分集与分镜，**无法恢复** | 弹窗看清 N 集 M 分镜再确认；只调个别镜头用上拆/下拆 |
| 资产名过于相似 / 太短 | 匹配张冠李戴或匹配不上 | 5 字以内须全等；相似角色加别名区分 |
| 生成失败后反复原样重提 | 重复排队、重复扣费（失败会退但耗时间） | 先看错误信息：垫图失效就修素材，额度不足就充值 |
| 只把成片留在软件里 | 极端情况（云端对象丢失且无本地副本）无法找回 | 定稿视频逐镜「导出」本地留档 |
| 换电脑直接登录 | 机器码拦截无法进入 | 先联系服务商解绑，再在新机登录 |
| 靠请求记录长期对账 | 记录约 30 天后清理 | 需要留档的账目及时记录 |
| 在画布堆几十个资产图节点 | 画布卡顿 | 资产图用资产助手按需拖入，用完可删（图仍在资产库） |
