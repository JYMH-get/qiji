# 教程 0 · 开始之前：注册、登录与界面总览

## 0.1 注册账号

你需要一枚**激活码**（由服务商提供）。

1. 打开软件，登录页切到「注册」标签。
2. 依次填写：
   - **账号**：自定义，之后用它登录；
   - **密码**：自定义；
   - **用户名**：昵称，可用中文，留空则显示账号；
   - **激活码**：服务商发给你的码。
3. 点「注册并登录」，直接进入软件大厅。

三件事请记住：

- **注册即绑定这台电脑。** 之后换电脑登录会被拦截，需联系管理员解绑。
- **激活码有有效期**（1 天 / 3 天 / 30 天 / 永久），从注册这一刻起算。到期后能登录看项目，但不能生成，需联系服务商续期。
- **忘记密码没有自助找回。** 联系服务商解绑账号后，用原激活码重新注册即可。

## 0.2 认识主界面

登录后你会接触到这些区域：

| 区域 | 位置 | 作用 |
|---|---|---|
| 大厅 | 启动首页 | 项目列表、新建项目 |
| 标题栏 | 顶部 | 模式切换（表格/画布）、个人中心、提交历史 |
| 左侧边栏 | 项目内 | 剧本编辑、五类资产页、视频界面 的导航 |
| 停靠栏 | 右侧 | 资产助手、简一助手 两个悬浮面板的开关 |
| 个人中心 | 标题栏按钮 | 积分、请求记录、兑换码、LibTV/即梦授权 |

## 0.3 两种创作模式

- **表格创作（资产模式）**：结构化流水线，剧本 → 资产 → 分镜表格，一步一个界面。**新手从这里开始。**
- **画布创作（画布模式）**：自由节点画布，所有步骤都是可连线的节点。适合精修和实验。

两者是**同一份项目数据的两个视图**，标题栏随时切换，不存在"选错模式"。

# 教程 1 · 30 分钟跑通第一集：从小说到成片

本章是主线教程。目标：拿到一部小说，产出第 1 集的全部分镜视频。跑通一遍后，后面所有章节都是对本流程某一步的深化。

## 第 1 步 · 建项目（1 分钟）

1. 大厅 →「新建项目」。
2. 填项目名，选**画风预设**（3D 国漫 / 2D 手绘 / 写实等）。

> ⚠ 画风是全项目的风格锚点，所有资产和分镜出图都会继承它。建项目前想清楚，中途换画风意味着已出的图风格不统一。

3. 点「表格创作」进入项目。

## 第 2 步 · 放入剧本并拆分（3 分钟）

1. 剧本编辑页，把小说全文粘贴进正文区。
2. 点「**剧集拆分**」——把全文拆成一集一集：
   - 文本没有明显分隔标记 → 选 LLM 智能分集；
   - 文本已按空行/章节分好 → 用快速拆分（详见教程 2）。
3. 点「**资产拆分**」——AI 提取全部角色、场景、生物、群像、物品：
   - 提取是流式的，界面上六个计数卡实时上涨；
   - 完成后检查一眼「项目视觉圣经」（全项目统一的风格描述），不符合预期可手动修改。

两个按钮相互独立，都要点，顺序不限。

## 第 3 步 · 出资产形象（5~10 分钟）

进入左侧的资产页面（角色 / 群像 / 场景 / 生物 / 物品）：

1. **先出主角和主场景**——它们出场率最高，是画面一致性的根基。
2. 每张资产卡：检查/微调出图提示词 → 点生成。不满意再点，历史图全保留，随时换主图。
3. 不必一次出完所有资产。分镜里用到谁再补谁。

> 推荐顺序：主角 → 主场景 → 高频道具 → 配角按需。

## 第 4 步 · 分镜推理（3 分钟）

1. 左侧进入视频界面，选「第 1 集」。
2. 点「**智能推理**」。AI 把整集拆成分镜，每镜自动产出：
   - 分镜原文（对应的剧本片段）
   - 故事板提示词（出图用）
   - 视频提示词（出片用）
   - 建议时长
3. 通读一遍，重点看前 3 镜。个别镜头不满意 → 该镜点「单镜推理」重跑（会自动参考上下镜内容，保证连贯）。

## 第 5 步 · 匹配素材（2 分钟）

1. 点「**提取资产**」：系统扫描各分镜的原文和提示词，按名称自动匹配项目资产，把资产图垫进素材区，提示词顶部写入图例：

   ```
   【素材图例】@Image1 是 张三，@Image1的声音参考@Audio1
   ```

2. 抽查几个分镜：垫图齐不齐、造型对不对。缺的从**资产助手**（右侧停靠栏）直接拖进素材区。

## 第 6 步 · 出故事板图（5 分钟）

1. 逐镜点「生成故事板图」（垫图会作为参考随单发送）。
2. 不满意：改提示词 → 重新生成。所有生成过的图都在历史条，点击即可回退。

## 第 7 步 · 出视频（10 分钟+）

1. 工具栏确认四项参数：**模型源 / 模型、时长、比例、分辨率**（可选档位由模型决定）。
2. 点「生成视频」。建议带故事板图作**首帧**，画面更可控。
3. 视频生成慢，**多镜并行提交**后可以去干别的：
   - 中途关软件没关系，重开项目自动重连任务；
   - 失败自动退积分。

## 第 8 步 · 精修与导出

1. 不满意的镜头：换提示词/换垫图重跑；需要更清晰 → 右击主视频 →「超分」（详见教程 6）。
2. 相邻镜头衔接生硬 → 用首帧/尾帧续接技巧（教程 6.4）。
3. 全部满意后逐镜「导出」到本地，进剪辑软件合成整集。

**至此主链路完成。** 下面各章是对每一步的深化。

# 教程 2 · 剧本拆分：选对拆分方式，管好分集

## 2.1 四种快拆 + LLM 分集怎么选

| 方式 | 适用文本 | 效果 |
|---|---|---|
| LLM 智能分集 | 无明显分隔标记的原始小说 | AI 按剧情节奏分集，最省心但耗积分 |
| 空行拆分 | 段落间已用空行分隔 | 一个空行块一集 |
| n-1 | 已有分集但要合并成一集 | 全文归一集 |
| n-n（默认） | 已按章节/集分好 | 一段一集 |
| 场n-n | 剧本带「场」字标记 | 按场次分集 |

## 2.2 重新拆分的代价

已经产生分镜成果（推理结果、故事板图、视频）后再点「剧集拆分」，会弹出确认框，明确列出将被覆盖的集数和分镜数。**确认后不可恢复。**

原则：分集结构尽量在做分镜之前定稿；中后期只想调整某一集的内容，去视频界面用「上拆/下拆」微调分镜，不要重拆全书。

## 2.3 手动增删分集

- 画布模式下，顶部分集选择器旁有「＋分集」，可直接新建空分集（同步出现在视频界面）。
- 视频界面可删除分集（有确认框）。

# 教程 3 · 资产体系：形象定稿、造型变体与音色

## 3.1 理解资产编号

资产拆分后，每个资产有一个项目内编号：**C** 核心角色 / **A** 配角 / **G** 群像 / **S** 场景 / **M** 生物 / **P** 道具。变体在编号后加字母（如 C01A = C01 的第一个变体造型）。

## 3.2 基础形象定稿

1. 资产卡上先读一遍 AI 生成的出图提示词，按需修改（外貌细节、服装、配色）。
2. 生成 → 对比 → 再生成。历史图全部保留，点历史条换主图。
3. 也可以「上传本地图」用自己的设定图作为形象。

> 基础形象是后续一切变体和分镜垫图的底图，**值得多花时间定稿**。

## 3.3 造型变体（战损 / 换装 / 状态变化）

场景：剧情后期主角要有「战损」形态，但不能画着画着变成另一个人。

1. 在角色卡点「生成造型变体」，输入变化描述（如「战损：衣衫破损、面部血污」）。
2. AI 以基础形象为底做**图生图**：锁定角色 DNA（脸型、发色、体态），只改变你指定的项。
3. 变体出现在该角色的造型列表，可继续多次生成、换主图、重命名。

**在分镜中使用指定造型**：

1. 打开资产助手 → 找到该角色 → **右击卡片选中目标造型**。
2. 之后「提取资产」匹配到该角色时，垫的就是选中造型的图。
3. 做完该集记得切回默认造型，避免下一集误用。

## 3.4 绑定音色

1. 角色卡上传一段音频（该角色的声音参考）。
2. 之后任何分镜匹配到该角色，音频自动跟着垫图进素材区，图例写明「@ImageN的声音参考@AudioM」——支持音频参考的视频模型会拿它对齐声线。
3. 资产助手里绑了音色的卡片右下角有音频角标，点击可试听。

## 3.5 资产的命名与匹配规则

「提取资产 / 匹配素材」按**名称**匹配：资产名（或造型名、别名）出现在分镜原文/提示词里即命中。轻微的格式差异（空格、标点、全半角）不影响；名称完全不同则匹配不到——**给资产起和剧本里一致的名字**是匹配率的关键。

# 教程 4 · 分镜工作台：推理、提示词与素材的精细控制

## 4.1 三种推理方式的选择

| 方式 | 输出 | 什么时候用 |
|---|---|---|
| 智能推理（整集多卡） | 全部分镜 + 两套提示词 + 时长 | 每集的第一遍，主力用法 |
| 智能拆分 | 只拆原文，不写提示词 | 想完全自己写提示词 |
| 单镜推理 | 重跑单个分镜 | 个别镜头返工；自动带上下镜上下文 |

「一键推理所有单镜」= 逐镜批量单推理，适合整集都想按单镜上下文重写一遍时用。推理模板可在视频设置里更换（多卡/单卡各一个下拉）。

## 4.2 提示词编辑的完整武器库

- **@ 引用**：输入 `@` 弹出素材候选（按数字 1-9 快选），插入 `@Image1`/`@Video1`/`@Audio1` 胶囊，精确指定"用哪个素材"。
- **# 导入**：快速导入内容到提示词。
- **▦ 预设方案**：插入预设胶囊（如「6宫格电影故事板」），提交时自动展开成完整预设词。
  - 双击胶囊 = 就地展开成可编辑文本；
  - 同一互斥组只保留一个（插 4 宫格自动顶掉 6 宫格）；
  - 设置 → 预设方案 可建**自定义预设**（可设互斥组、前缀/后缀位置）。
- **放大编辑**：点提示词框的放大按钮 → 大窗编辑，支持查找替换（命中高亮、全部替换）、「匹配资产」按钮。关窗**默认保存**，点「取消」才丢弃。

## 4.3 素材区管理

- 三类素材：图片、视频、音频。
- 添加：提取资产自动匹配 / 「＋本地」 / 从资产助手拖入 / 跨分镜拖拽复制。
- 删除素材时，提示词里的图例条目和 @ 编号**自动同步修正**，不会留残句。
- 图例行（`【素材图例】@Image1 是 xxx`）由系统维护，增删素材自动重建。

## 4.4 分镜原文的微调

- **上拆 / 下拆**：把本镜原文的首行/末行移给相邻分镜——调整镜头节奏时比重新推理快得多。
- 原文可直接编辑，编辑后单镜推理即按新原文出卡。

## 4.5 模型与参数

- 模型选择是两级：**模型源**（服务商模型 / LibTV / 即梦）→ 本地渠道再选**款式**。
- 时长、比例、分辨率的可选档位跟随所选模型自动切换。
- 视频设置里的选择随项目记住，单镜可临时覆盖模型。

# 教程 5 · 图视同源工作流：提示词只写一遍

**适合谁**：不想维护"故事板提示词 + 视频提示词"两套文案的用户。

1. 视频界面 → 视频设置 → 打开「**图视同源**」开关；同源推理模板（多卡/单卡）各选一次，随项目记住。
2. 点「智能推理」：每镜只产出**一段**同源提示词，提示词区变成单栏。
3. 之后改提示词只改这一处，**出图和出视频都用它**。
4. 生成故事板图时的隐藏加成：系统按提示词里的镜头数**自动追加宫格预设**——
   - ≤4 镜 → 4 宫格；5~6 镜 → 6 宫格；更多 → 9 宫格；
   - 提示词里已手写宫格指令则不重复追加；
   - 视频侧不受影响（宫格只补图）。
5. 「同步本集到画布」后结构也不同：同源提示词是**独立节点**，图片节点和视频节点并联接它——画布上改同源节点一处，两路同时生效。

> 注意：同源模式下推理**必须先出结果**再生成故事板图，宫格才知道该用几格；未推理直接生成不补宫格。

# 教程 6 · 视频生成与后处理：超分、去字幕、镜头衔接

## 6.1 生成策略

- 带故事板图作首帧 = 画面更可控，推荐默认开。
- 多镜**并行提交**再统一验收，比逐镜等更省时间。
- 生成中关软件无碍：重开项目自动重连，任务不丢、不重复扣费。

## 6.2 超分（画质增强）

1. 右击主视频 →「超分…」。
2. 弹窗选模型档位和目标分辨率（可选档位以服务商开放为准），确认提交。
3. 结果作为**派生记录**（标号 `v1+`）出现在历史条：
   - 左击 = 设为主视频；
   - 右击 = 对比原视频（全屏滑杆分割对比，双路同步播放）/ 设为主视频 / 删除。

故事板图同理：右击图 →「图像超分…」，可放大到 2K/4K，结果进故事板历史条（右击可对比原图）。

## 6.3 去字幕

1. 右击主视频 →「去字幕…」。
2. 两种范围：
   - **全屏**：自动检测消除（默认）；
   - **局部**：在预览画面上**拖拽画框**圈出要擦除的区域（可画多个、可删）。
3. 结果为派生记录（标号 `v1-`），操作同上。

派生记录可以链式处理（对超分后的 v1+ 再去字幕），标号始终只有一个后缀、同标号后到覆盖。

## 6.4 镜头衔接：首尾帧续接

场景：镜头 A、B 是连续动作，各自独立生成会跳戏。

1. 先把 A 的视频定稿。
2. 右击 A 的主视频 →「**尾帧**」→ 发送到下一镜 B。
3. B 的素材区收到 A 的尾帧图，生成 B 时以它作首帧——动作无缝续接。
4. 「首帧」同理可发给上一镜。
5. 需要中间片段：右击 →「分段…」，弹窗拖选起止点，裁出真 mp4 片段（本地 ffmpeg，秒出）。

# 教程 7 · 画布模式入门：节点、连线与裂变

## 7.1 心智模型

画布 = 把表格流程摊开成可见的节点图。**8 类节点**：

| 节点 | 作用 |
|---|---|
| 文本 | 存放/编辑一段文本（剧本、提示词源） |
| 资产拆分 | 输入剧本 → 提取五类资产 |
| 剧集分集 | 输入剧本 → 拆分集 |
| 智能推理 | 输入原文 → 出分镜卡（多卡/单卡/智能拆分模板可换） |
| 图片生成 | 出图（提示词 + 素材区） |
| 视频生成 | 出片（提示词 + 素材区 + 时长/比例/分辨率） |
| AI 对话 | 单轮对话，可串联记忆 |
| 上传 | 承载本地文件（图/视频/音频） |

**每个分集是一块独立画布**（顶部下拉切换，＋分集新建）。空白处右键 = 新建节点列表；从节点边缘拖线到空白 = 生成并连接新节点。

## 7.2 连线的语义：所有输入都看得见

- 上游**媒体**（图/视频/音频）→ 自动出现在下游素材区（排自加素材前面）。
- 上游**文本** → 下游提示词框出现青色「▤ 上游文本N」胶囊，提交时还原为上游实际文本。
- 匹配项目资产 = **手动**点「匹配资产」（连线不会自动匹配）。

一句话：**画布没有隐形提交**——节点提示词框和素材区里看到什么，提交的就是什么。

## 7.3 裂变：让流水线自己长出来

推理/拆分节点运行时，自动生出下游节点，且是流式的（AI 每写完一项，节点立即蹦出）：

- 智能推理 → 每镜一条「分镜n原文 → 分镜n故事板 → 分镜n视频」流水线；
- 资产拆分 → 每个资产一个图片节点（带资产名和整段提示词）；
- 剧集分集 → 每集一个智能推理节点。

三个配套操作：

- **二次解析（补齐缺漏）**：右击源节点，对已有结果重新解析，只补缺失节点，不重跑、不动已有节点。
- **分镜n原文节点可直接重推理**：改原文 → 点运行 = 单镜重跑，向下游裂变新流水线。
- **拆分 / 重组**：右击原文节点「拆分…」按行拆成多个原文节点（分镜1-1、1-2…）；多选后右键「重组文本」按阅读顺序合回。

## 7.4 与表格模式互通

视频界面点「**同步本集到画布**」：把本集的 剧本 → 分集 → 分镜 流水线投影到画布（幂等，重复点不会重复建）。资产不投影（需要单个资产图时从资产助手拖入）。

# 教程 8 · 画布模式进阶：堆叠、分镜组与批量操作

## 8.1 结果堆叠：一个节点管理多版结果

图片/视频节点每次生成，旧结果自动进**堆叠**（节点显示纸边 + 层数角标）：

- 选中节点按 **C**（或右键「打开堆叠」）→ 抽屉网格浏览全部版本；
- 右击某张 →「设为主图」（主图 = 对外输出、参与连线的那张）；
- 双击 → 灯箱放大；
- **拖出**某张到画布（悬停 1 秒后松手）= 复制成新节点；
- 把两个同类节点**拖叠**（悬停 1 秒）= 合并堆叠；
- 悬停节点工具栏的「上传」可把本地文件（可多选）直接追加进堆叠。

## 8.2 多方案对比的标准打法

1. ALT+拖动目标节点 = 原位留完整克隆、拖走一份副本（带上游连线）。
2. 给几个副本写不同提示词，Ctrl+Enter 并行运行。
3. 用堆叠抽屉/灯箱对比，最佳一版「设为主图」，其余节点删除。
4. 定稿的图右击「**绑定到资产…**」沉淀回项目资产库（可绑给现有资产或新建资产）；音频节点同样可绑为某资产的音色。

## 8.3 分镜组与宫格

**合并为分镜组**：多选 ≥2 个有图的节点 → 右键「合并为分镜组」→ 得到一个宫格容器节点：

- 拖动格子排序、切换宫格规格（2×2~4×4）和比例、显示序号；
- 「拼接」输出一张 2K / 4K 无缝大图（新图片节点承载）；
- 「解组」把每张图还原成独立图片节点。

**宫格切分**（反向）：图片节点右击「宫格切分…」→ 图上叠宫格、点选要切出的格子 → 切出新的分镜组。配合 6 宫格故事板预设使用：一张 6 宫格图切成 6 个独立镜头图。

## 8.4 批量操作

多选（框选 / Ctrl+点选）后：

- 悬浮工具栏 / 右键：**匹配素材（N）**、**一键增加预设**、**一键检查素材**、合并为分镜组、重组文本、打组/解组；
- 多选拖动整组移动；从任一选中节点拉线 = 全部选中节点一起连到落点。

## 8.5 保持画布整洁

- 「**整理**」按钮：相连的节点作为族群内部排版（上游左、下游右），族群间拼图式紧凑排列；间距可在 设置 → 快捷键 → 画布整理 自定义；一次撤销可回退。
- 「重叠」开关（小地图旁）：关闭时画布严格不重叠，拖动会自动挤开让位；打开则允许自由堆放。
- 「吸附」开关：拖动时对齐其它节点的边缘/中线（青色参考线）。
- 同类节点**生成设置自动联动**：改一个图片节点的比例，全画布图片节点跟随（提示词、内容不联动）。

## 8.6 快捷键自定义

设置 → 快捷键：14 个动作全部可改绑（点键位胶囊进入录制模式），可单项/全部恢复默认。默认键表见附录 A。

# 教程 9 · 团队协作：共享素材库

**场景**：工作室多人做同一 IP，角色形象必须全员统一。

## 9.1 结构与角色

三级结构：**共享库**（服务商创建、密码保护）→ **共享文件夹**（用户可新建）→ **素材**。入口在资产助手的「共享资产」页。

## 9.2 管理者（一次性）

找服务商开通共享库，拿到**库名**和**加入密码**，发给团队成员。约定文件夹规范（如按 角色/场景/道具 分建）和素材命名规范（带角色名，方便使用者自动匹配）。

## 9.3 素材提供者：分享定稿资产

1. 先在自己项目里把资产定稿（教程 3）。
2. 右击资产 / 造型 / 画布节点 / 资产助手卡片 →「**添加到共享资产**」。
3. 弹窗选目标库和文件夹，确认。

> 分享登记的是云端记录，**不重复上传文件**，秒完成。画布节点可多选批量分享。

## 9.4 素材使用者：加入并取用

1. 资产助手 → 共享资产页 → 搜索库名 → 输入密码加入。
2. 进入库自动列出文件夹；进入文件夹点「**获取**」下载素材到本地（带进度条；再次获取只补新增）。
3. 素材按 角色/场景/生物/群像/道具/其他 分类筛选。
4. 取用方式二选一：
   - 直接**拖拽**共享卡到分镜素材区/画布当垫图；
   - 右击 →「**添加到项目资产…**」正式绑进自己项目（图片绑形象、音频绑音色），之后走正常匹配流程。

软件会记住你上次浏览到哪个库、哪个文件夹。

# 教程 10 · 接入即梦 / LibTV：用自己的账号出片

**适合谁**：已有即梦或 LibTV 会员/额度的用户。生成消耗对方平台的额度，Qiji 侧只收少量手续费（实际价格见界面积分角标）。

## 10.1 连接 LibTV

1. 个人中心 →「LibTV 授权」→ 点连接。
2. 自动打开浏览器 → 登录 LibTV → 回到软件显示昵称即成功。
3. 视频模型下拉出现「LibTV · Seedance 2.0 / Fast」。

## 10.2 连接即梦

1. 个人中心 →「即梦授权」→ 点连接。
2. 浏览器打开授权页，按提示输入软件显示的**配对码**确认。
3. 模型下拉出现「即梦 · Seedance 2.0 / Fast / VIP / Fast VIP」。

## 10.3 使用要点

- 模型源选「即梦」或「LibTV」后，旁边的「模型」下拉选款式；参数档位自动切换成该渠道支持的范围（如即梦仅 VIP 款开放 1080p/4K）。
- 垫图、垫视频、音频参考都会随单发送；提示词里的 @ 引用会转换为对方平台的素材引用。
- **排队慢是对方平台的常态**（尤其即梦免费队列）：生成超时被打断后任务不丢，点「重连原任务」继续等结果即可。
- 若你在终端已登录过对方 CLI，软件会直接复用登录态，无需重新授权。

# 教程 11 · 日常维护：积分、素材体检与账单

## 11.1 积分管理

- **余额**：个人中心概览页；顶部余额随心跳自动刷新（≤30 秒）。
- **充值**：个人中心 → 兑换码。
- **计费规则**：按模型定价，视频按秒；界面积分角标显示预估（预估即实扣）；余额不足直接拒单不扣费；任务失败自动退款。

## 11.2 账单核对

个人中心 →「请求记录」：每次任务的时间、步骤、模型、扣分、状态，可按状态筛选、展开详情。失败任务标「已退还」。

## 11.3 素材体检（检查素材）

素材字节存在云端，长期项目建议定期体检：

1. 入口：资产页右上角「**检查所有资产**」/ 资产助手标题栏同名按钮 / 任意资产、节点右击「检查素材」。
2. 系统逐个探测云端链接：
   - 正常 → 绿色计数；
   - 死链但本机有本地副本 → **自动重传修复**；
   - 无法修复 / 无云端记录 → 报告点名列出，建议重新生成或重新上传使其入库。

什么时候跑：发现图片"短暂显示后裂开"、换机后图片加载失败、交付前的最终检查。

## 11.4 数据安全习惯

- 项目自动保存 + 备份 + 损坏自愈，正常使用无需手动操作。
- 生成中途关软件安全（自动重连）；但**不要在保存瞬间强杀进程或断电后直接删除项目文件夹内的 .bak 文件**。
- 所有删除/覆盖操作都有深色确认框（Esc/点遮罩 = 取消）；画布结构操作可 Ctrl+Z 撤销，资产/分集删除确认后不可恢复。
