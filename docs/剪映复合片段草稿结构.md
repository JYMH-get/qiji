# 剪映复合片段（子草稿）草稿结构 · 逆向实录与导出规格

> 2026-08-19 实锤。依据：用户真实草稿「发配雪关，零下三十度我靠暖棚养活一座城-副本(1)」
> （剪映 10.9，含 6 个复合片段实例）+ 四轮探针草稿真机验证（v1→v4 二分收敛）。
> **这是复合片段导出功能的格式依据文档**——pyJianYingDraft 不支持生成复合片段，此格式无其它公开资料，勿删。

## 0. 结论（先看这个）

复合片段**可以由我们的 TS 导出器生成**，纯明文 JSON + 文件夹，零加密零资源表。
在我们现有 5.9 明文模板（jianyingDraft.ts）基础上，**只需在复合相关的局部按下述「样本形态」写**（探针 v4 实锤的充分条件集），其余（普通片段/轨道/顶层字段）保持现状零改动：

1. **虚拟视频素材**（materials.videos 里一条）：样本形态克隆（见 §2.2）；
2. **复合片段本体**（时间轴 segment）：样本 12 键精简形态（见 §2.1）；
3. **复合段的 extra_material_refs**：8 组伴生素材，顺序
   `drafts → speeds → placeholder_infos → hsl → canvases → sound_channel_mappings → material_colors → vocal_separations`
   （⚠ v1/v2 只挂 speeds 时剪映**认得出复合片段但不渲染画面**——伴生素材组是渲染的必要条件之一）；
4. **materials.drafts 条目**（8 键，含子时间轴完整内联，见 §2.3）；
5. **subdraft/\<UUID\>/ 三件文件**（子草稿 wrapper + config + 封面，见 §3）；
6. **draft_meta_info.json 素材登记**（否则素材栏为空，见 §4；此项与复合无关、对普通导出同样生效）。

## 1. 磁盘布局

```
<草稿根>/<草稿名>/
├─ draft_content.json          ← 主时间轴（我们写 5.9 明文模板；剪映 7+ 自己保存时会加密，但读明文没问题）
├─ draft_meta_info.json        ← 草稿元信息 + 素材面板登记（§4）
├─ assets/…                    ← 我们的自包含素材（现状不变）
└─ subdraft/
   ├─ <UUID>/draft_content.json    ← 子草稿 wrapper（明文；即使主草稿被剪映加密，子草稿仍保持明文）
   ├─ <UUID>/sub_draft_config.json ← 子草稿元信息
   ├─ <UUID>/draft_cover.jpg       ← 封面（可选观感件）
   └─ draft_content.json / sub_draft_config.json   ← 松散副本（剪映自己会写一套；我们照写同内容防新版按此路径找）
```

真实草稿里 4/6 个复合实例的 `draft_file_path` 指向共享/陈旧的松散文件 → **主时间轴渲染的真正数据源是
drafts 素材里的内联 `draft` 副本**，subdraft 文件夹主要服务「双击进入编辑/封面」。

## 2. 主 draft_content.json 里的复合三件套

### 2.1 复合片段（segment，挂在普通 video 轨上）

样本 12 键精简形态（对比我们普通段 26 键——**复合段照这个写，不带 speed/volume/render_index 等我们方言字段**；
v4 实测混排无碍：同轨 m1 我们方言 + m2 样本方言）：

```json
{
  "responsive_layout": {}, "render_timerange": {},
  "id": "<UUID>", "enable_adjust_mask": false, "enable_hsl": false,
  "extra_material_refs": ["<drafts素材id>", "<speed>", "<placeholder_info>", "<hsl>", "<canvas>", "<sound_channel_mapping>", "<material_color>", "<vocal_separation>"],
  "material_id": "<虚拟素材id>",
  "target_timerange": { "start": …, "duration": <子时间轴总时长> },
  "source_timerange": { "start": 0, "duration": <子时间轴总时长> },
  "source": "segmentsourcenormal",
  "hdr_settings": { "mode": 1 },
  "clip": { "transform": { "x": 0, "y": 0 }, "flip": {} }
}
```

复合片段在剪映里就是「一段视频」——可被裁剪/分割/变换，source 窗口即子时间轴的时间窗。

### 2.2 虚拟视频素材（materials.videos）

`path` 为空 = 无真实文件；`extra_type_option: 2` 标记复合：

```json
{
  "path": "", "extra_type_option": 2, "duration": <子时长>, "is_set_beauty_mode": true,
  "crop": {}, "video_mask_shadow": { "resource_id": "", "path": "" },
  "check_flag": 62978047,
  "video_mask_stroke": { "path": "", "type": "", "resource_id": "" },
  "material_name": "复合片段N", "id": "<UUID>", "width": 1920,
  "video_algorithm": { "story_video_modify_video_config": {}, "path": "" },
  "material_id": "", "matting": { "path": "" }, "beauty_face_auto_preset": {},
  "height": 1080, "type": "video", "stable": { "time_range": {} }, "is_copyright": true
}
```

### 2.3 drafts / combination 素材（materials.drafts）

8 键（主草稿侧；wrapper 侧另有富键版见 §3）：

```json
{
  "id": "<UUID>", "type": "combination", "combination_type": "none",
  "combination_id": "<UUID·复合实例id>",
  "draft_cover_path":  "subdraft/<X>/draft_cover.jpg",
  "draft_config_path": "subdraft/<X>/sub_draft_config.json",
  "draft_file_path":   "subdraft/<X>/draft_content.json",
  "draft": { …子时间轴完整内联… }
}
```

**内联 `draft`**＝精简草稿形态（顶层 18 键：canvas_config{height,width} / color_space / config{maintrack_adsorb}
/ duration / function_assistant_info / id(=X) / keyframes / last_modified_platform / materials / name /
new_version / path:"" / platform / render_index_track_mode_on / smart_ads_info / tracks /
uneven_animation_template_info / version:360000）。其中：

- 轨道：`{ id, is_default_name, segments, type }`；
- 片段：12 键精简形态（同 §2.1 但无 drafts 引用），`extra_material_refs` 6 组伴生，顺序
  `speeds → placeholder_infos → canvases → sound_channel_mappings → material_colors → vocal_separations`；
- 伴生素材为**极简条目**：`speeds {id,type:"speed"}` / `placeholder_infos {id,type:"placeholder_info",meta_type:"none"}`
  / `canvases {id,type:"canvas_color"}` / `sound_channel_mappings {id,type:"none"}` / `material_colors {id}`
  / `vocal_separations {id,type:"vocal_separation"}`（hsl 仅主草稿复合段引用，内联段不带）；
- 视频素材：19 键 10.9 形态（path 可绝对可相对主草稿根；含 category_name:"local" / check_flag 62978047 /
  local_material_id(小写连字符 uuid) 等）。
- ⚠ 探针 v2 证明：主草稿仍是我们方言时，仅把内联换成样本方言**不足以**出画；v4 的最小集里内联用了样本方言
  ——内联方言是否必要未单独二分（保持样本方言即可，别省）。

## 3. subdraft/\<X\>/ 三件文件

- **draft_content.json（wrapper）**：一份完整草稿（10.9 富键形态），时间轴=1 条 video 轨 1 个复合段，
  其 materials.drafts[0]（富键版：另含 aimusic_mv_template_info / category_id / category_name / formula_id /
  name / precompile_combination:false）内联同一份子时间轴；`draft_file_path/config_path/cover_path` 用**绝对路径**
  指向自身。顶层 `id` = X。双击进入复合编辑读的就是它。**照真样本克隆重映射生成**（探针 v2-v4 沿用同一份，验证通过）。
- **sub_draft_config.json**：
  `{ audio_path:"", cover_height:180, cover_path:"draft_cover.jpg", cover_width:320, create_time:<epoch秒>,
  draft_json_file:"draft_content.json", id:X, import_time_ms:<epoch毫秒>, is_from_multi_timeline:false,
  is_from_sub_draft:true, material_color_tag:"", name:"复合片段N", project_id:X,
  rough_cut_duration:<子时长>, rough_cut_start:0, source:"timeline", type:"video" }`
- **draft_cover.jpg**：任意 jpg 即可（观感件）。

id 形态：复合相关 id（X / combination_id / drafts 素材 id）用**大写连字符 UUID**（样本同形）；
我们既有素材/片段的小写 hex id 与之混用经 v4 实测无碍。

## 4. draft_meta_info.json 素材登记（素材栏）

`draft_materials` 里 `type:0` 桶的 `value` 逐素材登记（缺失 = 素材面板空 = 用户没法二次编辑取素材，探针 v2 实锤修复）：

```json
{ "create_time": <epoch秒>, "duration": <us>, "extra_info": "<文件名>", "file_Path": "<绝对路径>",
  "height": 1080, "id": "<UUID大写>", "import_time": <epoch秒>, "import_time_ms": <epoch微秒级*1e6>,
  "item_source": 1, "md5": "", "metetype": "video", "roughcut_time_range": { "duration": <us>, "start": 0 },
  "sub_time_range": { "duration": -1, "start": -1 }, "type": 0, "width": 1920 }
```

（`metetype` 是剪映原文拼写，勿"修正"；图片用 "photo"，音频待验证（推测 "music"）。）

## 5. 探针二分实录（复现方法论）

| 版本 | 主草稿 | 内联/子草稿 | meta 登记 | 结果 |
|---|---|---|---|---|
| v1 | 我们 5.9 方言 + 复合三件套（仅 speeds 伴生） | 我们 5.9 方言 | 无 | 识别复合✓ 双击✓ **画面✗**（编辑后临时可显、重开又坏）素材栏空 |
| v2 | 同 v1 | **样本方言** | **有** | 画面仍✗；素材栏✓ → 病根在主草稿侧 |
| v3 | **整体样本方言** | 样本方言 | 有 | **画面✓ 重开✓** → 病根锁定 draft_content 方言 |
| v4 | 我们方言 + **复合局部三处样本形态** | 样本方言 | 有 | **画面✓ 重开✓** → 最小改动集成立 |

要点：
- 「编辑复合后临时能显示、重开又坏」＝子编辑器现场合成掩盖了主侧接线问题——进复合编辑只重写 subdraft，不修主时间轴的复合段；
- `Resources/combination` 为空、`precompile_combination:false`——渲染是**实时合成内联子时间轴**，不依赖预合成缓存；
- ⚠ 剪映打开过的草稿会被**重存为加密**（draft_content/meta 都会）——探针复测必须换新文件夹，别在旧探针上二次手术；
- 探针生成脚本（会话 scratchpad，临时）：jy-combo-probe.ts（v1 基座，走我们 buildDraftContent）+ jy-combo-probe-v4.py（复合局部手术）。

   与 `sub_draft_config.json`（路径仍双向限定草稿根下）+ 封面 jpg 复制；

   是独立 material 记录，但 path 指向同一文件——剪映本就一段一条 material，不冲突）。
