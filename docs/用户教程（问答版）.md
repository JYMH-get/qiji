# Qiji 漫剧创作平台 · 用户教程

> 本教程分两部分：**第一部分「问答速查」**按主题整理常见问题，适合随用随查；**第二部分「应用实战」**是场景化的手把手流程，适合新手跟着做一遍。
> 注：部分功能入口由服务商配置开关（可用模式、可用模型、共享素材库等），如果你在软件里找不到教程中提到的某个入口，请先联系你的服务商确认是否已开通。

---

# 第一部分 · 问答速查

---

## 一、账号与登录

### Q1：我拿到了激活码，如何开始使用？
1. 打开软件，登录页选择「注册」标签。
2. 填写：自定义账号、密码、用户名（昵称，可用中文，留空则显示账号）、激活码。
3. 点「注册并登录」即可进入软件。

注意：**注册时会绑定当前电脑**（机器码绑定）。之后换电脑登录会被拦截，需要联系管理员解绑后才能在新电脑使用。

### Q2：注册之后每次怎么登录？
登录页选择「账号登录」，输入账号和密码即可。软件会记住登录状态，通常无需每次输入。

### Q3：我忘记密码了怎么办？
软件内没有自助改密功能。请联系你的服务商/管理员在后台解绑你的账号，之后你可以用原激活码重新注册（重新设置账号密码）。

### Q4：账号有有效期吗？到期会怎样？
激活码分四档有效期：1 天 / 3 天 / 30 天 / 永久，**从首次激活（注册绑定机器）时开始计算**。到期后仍然可以登录查看项目，但无法再进行任何生成操作，界面会提示「账号已到期」。续期请联系你的服务商。

### Q5：在哪里查看我的积分余额和消耗？
点击顶部标题栏的「个人中心」。「概览」页显示积分余额、总消耗、账号信息、有效期等。

### Q6：如何给账号充值积分？
个人中心里有「兑换码」入口，输入服务商发给你的兑换码即可充入对应积分。

### Q7：我想查每一次生成花了多少积分，在哪看？
个人中心 → 「请求记录」页。可以按状态筛选，每条记录显示时间、步骤、模型、扣除积分、状态；点击可展开详情。**失败的任务会自动退款**，记录上会标「已退还」。

## 二、项目管理

### Q8：如何新建项目？
大厅点「新建项目」，填写项目名、封面（可选）、选择画风预设（如 3D 国漫、2D 手绘、写实等——画风会作为全项目的风格锚点，影响所有出图）。然后选择用「表格创作」还是「画布创作」打开。

### Q9：「表格创作」和「画布创作」有什么区别？选错了怎么办？
两者是**同一份项目数据的两个视图**，随时可以在顶部标题栏切换，不存在选错：
- **表格创作（资产模式）**：结构化界面，按 剧本 → 资产 → 分镜表格 的固定流程走，适合standard流水线作业。
- **画布创作（画布模式）**：自由节点画布，把每一步做成可连线的节点，适合灵活实验和精细控制。

建议新手先用表格模式跑通全流程，再进阶画布模式。

### Q10：项目会自动保存吗？会不会丢数据？
会自动保存，并且有多重保护：
- 原子写入 + 滚动备份（.bak），异常断电/崩溃后能自动恢复；
- 生成任务（出图、推理、视频）进行到一半关闭软件也没关系，**重新打开项目会自动重连原任务**继续等结果，不会重复扣费。

### Q11：重新打开软件后会回到上次的位置吗？
会。软件记住你上次所在的页面、分集、滚动位置，打开项目自动恢复。

## 三、剧本编辑与拆分

### Q12：拿到一部小说/剧本，第一步做什么？
进入项目后来到剧本编辑页，把剧本全文粘贴进去。然后有两个**相互独立**的按钮：
- **剧集拆分**：把全文拆成一集一集；
- **资产拆分**：从全文提取角色、场景、道具等资产。

两个都要做，顺序不限。

### Q13：剧集拆分有哪些方式？
下拉里可选：
- **LLM 智能分集**：让 AI 按剧情自动分集；
- **快速拆分**：按固定规则拆——空行分隔 / n-1 / n-n（默认）/ 场n-n（按"场"字标记）。

### Q14：我已经拆分过了，再点「剧集拆分」会怎样？
会弹出确认框，明确告诉你「再次拆分将覆盖现有 N 集分集及其全部分镜（含推理结果、故事板图、视频引用），覆盖后无法恢复」。点取消则一切保留。**已经开始做分镜的项目请谨慎重拆。**

### Q15：「资产拆分」会得到什么？
AI 会从剧本中提取五类资产，自动分流到五个资产页面：
- **角色**（C 编号）、**群像**（G）、**场景**（S）、**生物**（M）、**物品/道具**（P）

每个资产自带一整段出图提示词；同时生成**项目视觉圣经**（全项目统一的风格/色调描述），所有资产出图都会继承它。拆分是流式的，提取一个入库一个，可以边拆边看。

## 四、资产工作台（五类资产页）

### Q16：资产页面怎么用？
左侧边栏进入 角色 / 群像 / 场景 / 生物 / 物品 任一页面。每个资产卡片可以：
- **生成基础形象**：按资产自带的提示词出图；
- **生成造型变体**：在基础形象上做图生图变体（如战损造型、换装）——AI 会锁定角色 DNA 只改变指定项；
- **上传本地图**：用自己的图作为资产形象；
- 查看**主图 + 历史图**：多次生成的图都保留，可随时切换主图。

### Q17：如何给角色绑定音色？
角色页面的角色卡上有绑定音色入口，上传一段音频即可。绑定后，在分镜制作时匹配到该角色，**声音参考会自动跟着垫图一起进素材区**，提示词图例会写明「@ImageN的声音参考@AudioM」。

### Q18：提示词可以自己改吗？
可以。每个资产的出图提示词都可编辑；分镜页的提示词也全部可编辑（见第五章）。

## 五、视频 / 分镜工作台（核心流程）

### Q19：分集拆好了，怎么生成分镜？
进入视频界面，左侧选择分集，然后三选一：
- **智能推理**：一键把整集拆成分镜，每个分镜同时产出 原文 + 故事板提示词 + 视频提示词 + 建议时长（最常用）；
- **智能拆分**：只把原文拆成分镜，不写提示词（想自己写提示词时用）；
- **单镜推理**：对某一个分镜单独推理。单镜推理会自动带上「上一分镜/下一分镜」的内容作为上下文，保证前后连贯。

另有「一键推理所有单镜」按钮，逐镜批量推理。

### Q20：什么是「图视同源」？我该开吗？
视频设置里的开关。开启后，**故事板图和视频共用同一段提示词**——提示词区变成单栏，改一处，出图和出视频都跟着变。适合想减少维护两套提示词的用户。
额外福利：图视同源模式下生成故事板图时，系统会按提示词里的镜头数自动追加 4/6/9 宫格预设（把多个镜头画进一张宫格图）。

### Q21：「提取资产 / 匹配素材」是干什么的？
点击后，系统扫描分镜的原文和提示词，**按名称自动匹配**项目里的资产，把对应的资产图作为垫图放进该分镜的素材区，并在提示词顶部写入图例，例如：
`【素材图例】@Image1 是 张三，@Image1的声音参考@Audio1`
这样出图/出视频时 AI 就知道每张垫图是谁。绑定了音色的角色，音频会一并加入。
素材区里删除/添加素材，图例会自动同步，不会留下残句。

### Q22：素材区还能做什么？
- 支持图片、视频、音频三种素材；
- 可以手动「＋本地」添加、粘贴、或从资产助手拖入；
- 素材可以**跨分镜拖拽复制**；
- 提示词里用 `@Image1`、`@Video1`、`@Audio1` 引用具体素材（输入 @ 会弹候选列表，按数字 1-9 可快选）。

### Q23：什么是「预设方案」胶囊？
提示词工具栏的「▦ 预设方案」按钮。点选一个预设（如「6宫格电影故事板」），提示词框里会出现一枚琥珀色胶囊，**提交时自动展开成完整预设词**。要点：
- 双击胶囊可以就地展开成普通文本自行修改；
- 同一互斥组的预设（如 4/6/9 宫格）只能存在一个，插入新的自动替换旧的；
- 你可以在 设置 → 预设方案 里创建**自己的自定义预设**（可设互斥组、前缀/后缀位置）。

### Q24：提示词太长看不过来怎么办？
每个提示词框都有「放大」按钮，弹出大编辑窗，支持：
- **查找替换**（带命中高亮、全部替换）；
- 「匹配资产」按钮（以当前草稿匹配素材）；
- @ 引用、# 导入、预设胶囊照常可用；
- 关闭时**默认保存**（点「取消」才丢弃修改）。

### Q25：如何选择生成模型和参数？
分镜工具栏是两级选择：先选**模型源**（服务商提供的模型 / LibTV / 即梦），本地渠道再选具体**款式**（如 Seedance 2.0 / Fast / VIP）。时长、比例、分辨率的可选档位由所选模型决定，会自动收敛到该模型支持的范围。

### Q26：生成故事板图和视频的顺序是？
常规流程：分镜推理完成 → 点「生成故事板图」（可带垫图）→ 满意后点「生成视频」（可选择带故事板图作为首帧）。每个分镜生成过的图/视频都进**历史条**，点任意一条可切换当前主图/主视频。

### Q27：视频/图片质量不满意，有什么后处理？
右击主视频或故事板图，可选：
- **超分（画质增强）**：多档模型可选，提升到更高分辨率（具体可选档位以服务商开放为准）；
- **去字幕**：自动检测消除字幕，支持全屏或在画面上拖框指定局部区域；
- **图像超分**：故事板图放大到 2K/4K。

处理结果作为**派生记录**（标号如 v1+、v1-）出现在历史条，右击派生记录可「对比原图/原视频」（全屏滑杆对比）、设为主图/主视频、删除。

### Q28：还有哪些实用的分镜小工具？
- **首帧/尾帧**：把某镜视频的首/尾帧截成图，发给相邻分镜当垫图（保持镜头衔接）；
- **视频分段**：弹窗选起止点裁剪片段（内置 ffmpeg，出真 mp4）；
- **上拆/下拆**：把分镜原文的首/末行移给相邻分镜；
- **导出**：成片导出到本地；
- 表格列宽、行高会全局记忆。

## 六、画布模式（进阶）

### Q29：画布模式的基本概念？
画布上有 **8 类节点**：文本、资产拆分、剧集分集、智能推理、图片生成、视频生成、AI 对话、上传。节点之间连线表示数据流（上游的输出是下游的输入）。**每个分集是一块独立画布**，顶部下拉切换，也可以点「＋分集」直接新建。

### Q30：什么是「裂变」？
推理/拆分类节点运行时，会**自动生出下游节点**：
- 智能推理节点 → 每个分镜裂变出「分镜n原文 → 分镜n故事板 → 分镜n视频」三连流水线；
- 资产拆分节点 → 每个资产裂变出一个图片生成节点。

裂变是流式的：AI 每写完一个分镜/资产，节点就立即蹦出来。如果怀疑有遗漏，右击源节点选「二次解析（补齐缺漏）」，只补缺、不重跑、不动已有节点。

### Q31：连线之后输入是怎么传递的？
- 上游**图片/视频/音频**：自动出现在下游节点的素材区（排在自加素材前面）；
- 上游**文本**：下游提示词框会出现青色「▤ 上游文本N」胶囊，提交时自动还原为上游的实际文本——所有输入都在界面上明示，没有隐形提交；
- 匹配项目资产需要**手动**点面板/右键的「匹配资产」（不会连线自动匹配）。

### Q32：同一个节点生成了多次，旧结果去哪了？
全部保留在**堆叠**里。有多个结果的图片/视频节点会显示层数角标和纸边效果：
- 选中节点按 **C** 键（或右键「打开堆叠」）打开抽屉，网格浏览全部历史；
- 右击某张 → 设为主图；双击 → 灯箱放大；
- 抽屉里把某张**拖出到画布**（悬停 1 秒后松手）= 复制成新节点；
- 把两个同类节点**拖叠在一起**（悬停 1 秒）= 合并堆叠。

### Q33：节点右键菜单都有什么？
视内容而定，常用项：匹配资产、绑定到资产…（把节点结果图/音频存进项目资产）、拆分…（把原文按行拆成多个原文节点）、宫格切分…、图像超分…、超分/去字幕/分段（视频）、保存到本地、检查素材、添加到共享资产、上传（自定义结果入堆叠）、打开堆叠。
多选多个节点右键还有：匹配素材（N）、一键增加预设、一键检查素材、合并为分镜组、重组文本（拆分的逆操作）。

### Q34：什么是「分镜组」节点？
把多张图合并成一个宫格容器（2×2 到 4×4）：
- 多选 ≥2 个有图的节点 → 右键「合并为分镜组」；
- 组内可拖动排序、切换宫格规格和比例、显示序号；
- 「拼接」可输出一张 2K 或 4K 的无缝大图；「解组」把每张图还原成独立节点；
- 反向操作：图片节点右键「宫格切分…」，在图上点选要切出的格子，切出新的分镜组。

### Q35：画布太乱了怎么整理？
点「整理」按钮：自动把互相连接的节点作为一个族群内部排版（上游在左、下游在右），族群之间按拼图方式紧凑排列，整体趋向方形。节点间距可在 设置 → 快捷键 →「画布整理」区块自定义。整理可一次撤销。

### Q36：画布有哪些操作技巧？
- **粘贴**：系统剪贴板直接 Ctrl+V——截图变上传节点（自动传服务器）、文字变文本节点、复制的节点变克隆；
- **ALT+拖动** = 拖动复制（原位留完整克隆）；
- **全能复制**（Ctrl+Shift+C 或右键）：粘贴时自动把上游连线接回；
- 框选空白处可以**选中连线**，Delete 删除；单条连线右击直接删除；
- 中键/右键拖动 = 平移画布；滚轮缩放；双击图/视频 = 灯箱放大（滚轮可继续缩放）；
- 同类节点的**生成设置自动联动**：改一个图片节点的比例为 9:16，画布上其他图片节点自动跟随（提示词不联动）；
- 「重叠」「吸附」开关在小地图旁。

### Q37：快捷键可以改吗？
可以。设置 → 快捷键，14 个动作全部可自定义（复制/粘贴/撤销/重做/删除/全选/打组/运行节点/缩放/打开堆叠等），点键位胶囊即进入录制模式，可单项或全部恢复默认。

## 七、悬浮助手与全局工具

### Q38：「资产助手」是什么？
右侧停靠栏的悬浮面板，随时浏览项目全部资产（按 全部/角色/场景/生物/群像/道具/其他 分类）：
- **拖拽**资产卡到画布 = 建带图节点；拖到分镜素材区 = 加垫图；
- 右击卡片：选择造型（后续匹配优先用选中造型）、添加到共享资产、检查素材；
- 绑定了音色的资产卡右下有音频角标，点击试听；
- 双击卡片 = 灯箱放大；
- 顶部「检查所有资产」一键体检全项目资产的云端链接。

### Q39：「简一助手」是什么？
内置 AI 对话助手，支持多会话、多分身、流式回复。可以直接**粘贴截图/图片**进对话作为垫图发送。适合随手问剧情、润色提示词。

### Q40：「检查素材」是干什么的？什么时候用？
探测素材的云端（OSS）链接是否还存活：死链但本机有本地副本的会**自动重传修复**；无法修复和无云端记录的会在报告里点名。当你发现某些图片「短暂显示后裂开」或换机后图片加载失败时，跑一次检查即可。入口：资产页右上角「检查所有资产」、资产/节点右键、资产助手标题栏。

## 八、共享素材库

### Q41：共享素材库是什么？
跨用户共享资产的空间，三级结构：**共享库**（由服务商创建、密码加入）→ **共享文件夹**（用户可新建）→ **素材**。在资产助手的「共享资产」页使用。

### Q42：如何加入并使用共享库？
1. 共享资产页搜索库名，输入加入密码；
2. 进入库后自动列出文件夹；
3. 进入文件夹点「获取」，素材下载到本地（带进度条；再次获取只补新增）；
4. 素材可按 角色/场景/生物/群像/道具/其他 分类筛选；
5. 共享卡可以直接**拖拽**当垫图，或右击「添加到项目资产…」（图片绑为资产主图，音频绑为音色）。

软件会记住你上次浏览的库和文件夹。

### Q43：如何把自己的素材分享出去？
三个入口，右键都有「添加到共享资产」：画布节点（可多选）、资产助手卡片、资产页的资产/造型。选择目标库和文件夹确认即可——分享的是云端记录，**不会重复上传文件**，秒完成。也可以在共享页直接上传本机文件。

---

## 九、LibTV 与即梦（本地视频渠道）

### Q44：LibTV / 即梦渠道和普通模型有什么区别？
这两个渠道走**你自己的 LibTV / 即梦账号**生成视频（Seedance 2.0 系列），生成本身消耗的是你在对方平台的额度，不消耗 Qiji 积分；每次调用仅收取少量平台手续费（积分，实际价格见界面角标）。

### Q45：如何连接 LibTV？
个人中心 →「LibTV 授权」→ 点连接 → 自动打开浏览器登录 LibTV → 回到软件显示昵称即连接成功。之后视频模型下拉会出现「LibTV · Seedance 2.0 / Fast」。

### Q46：如何连接即梦？
个人中心 →「即梦授权」→ 点连接 → 浏览器打开授权页，按提示输入配对码确认 → 软件轮询完成登录。模型下拉出现「即梦 · Seedance 2.0 / Fast / VIP / Fast VIP」（VIP 款支持 1080p/4K）。
提示：即梦免费队列高峰期排队较长；若生成超时被打断，任务不会丢，点「重连原任务」即可继续等结果。

---

## 十、积分与计费

### Q47：各种操作怎么计费？
- 文本推理 / 出图 / 视频：按模型定价扣积分，视频通常按秒计费；界面上的积分角标显示预估费用；
- 余额不足时任务**直接拒绝**，不会扣费；
- 任务失败**自动退款**；
- LibTV / 即梦生成收固定手续费（见 Q44）；
- 超分 / 去字幕按次固定价。

### Q48：预估费用和实扣不一致？
预估即实扣（同一套价格投影）。如遇余额显示延迟，等心跳刷新（≤30 秒）或重开个人中心即可校准。

## 十一、常见问题排查

### Q49：图片在软件里显示不出来 / 裂开？
1. 先跑「检查素材」（见 Q40），死链会自动用本地副本修复；
2. 项目文件夹被移动/换机后本地副本缺失，且云端记录也失效的素材无法自愈——重新生成或重新上传即可重新入库。

### Q50：生成一直转圈很久没结果？
- 视频任务上限约 15 分钟、文本 20 分钟，超时会自动判失败并退款；
- 即梦排队慢是常态（见 Q46），用「重连原任务」续等；
- 关闭软件重开不影响在途任务，会自动重连。

### Q51：模型下拉里突然少了某个模型 / 多了新档位？
模型、价格、参数档位均由服务商实时下发（热更新，无需升级软件）。列表变化即服务商调整了开放范围，有疑问联系服务商。

### Q52：提示「无可用模型」怎么办？
无需手动选模型：未选择时软件会自动取该能力（文本/图像/视频）的第一个可用模型。出现该提示说明目录里没有拉到该能力的模型——软件会自动弹出 设置 → 管理端 页，确认管理端连接正常、目录拉取成功后重试。

### Q53：提示「服务暂不可用，请联系你的服务商」？
这是服务商侧的额度问题（非你的余额），直接联系你的服务商处理。

### Q54：删除操作有确认吗？误删了怎么办？
所有覆盖/删除类操作（重拆、删分集、删分镜、删资产、删素材等）都会弹出深色确认框，Esc/点遮罩=取消。画布内的结构操作支持 Ctrl+Z 撤销；已确认的资产/分集删除不可恢复，请谨慎确认。

# 第二部分 · 应用实战教程

> 以下每个实战都是一条完整可跟做的流程。建议先完成「实战一」跑通主链路，其余按需取用。

## 实战一：从一部小说到第一集成片（表格模式全流程）

**目标**：拿到一部小说，产出第 1 集的全部分镜视频。
**前提**：已注册登录、积分充足。

**第 1 步 · 建项目**
1. 大厅 →「新建项目」，填项目名，选一个画风预设（这一步决定全项目的画面风格，建议想清楚再选）。
2. 选择「表格创作」进入。

**第 2 步 · 放入剧本并拆分**
1. 在剧本编辑页粘贴小说全文。
2. 点「剧集拆分」：新手推荐先用 LLM 智能分集；如果你的文本本身已按空行/标记分好，用快拆更快。
3. 点「资产拆分」：等待 AI 流式提取（页面会实时显示 角色/场景/生物/群像/物品/变体 的计数上涨）。完成后顺手看一眼「项目视觉圣经」是否符合预期。

**第 3 步 · 出资产形象**
1. 依次进入 角色 / 场景 / 物品 等页面，先给**出场率最高的主角和主场景**生成基础形象（提示词可先微调再生成）。
2. 不满意就再生成——历史图都保留，点历史条随时换主图。
3. 建议顺序：主角 → 主场景 → 高频道具 → 其余配角按需。不必一次全出完，分镜里用到谁再补谁。

**第 4 步 · 分镜推理**
1. 进入视频界面，左侧选「第 1 集」。
2. 点「智能推理」，等整集分镜出齐（每个分镜自带 原文 + 故事板提示词 + 视频提示词 + 时长）。
3. 通读一遍提示词，重点检查开头 3 个分镜——不满意的镜头单独点「单镜推理」重跑（会自动参考上下镜保持连贯）。

**第 5 步 · 匹配素材**
1. 点「提取资产」：系统按名称把命中的资产图（和绑定的音色）自动垫进各分镜素材区，提示词顶部出现「【素材图例】@Image1 是 xxx」。
2. 抽查几个分镜：垫图是否齐、是不是你想要的造型。缺的手动从资产助手拖入。

**第 6 步 · 出故事板图**
1. 逐镜（或批量）点「生成故事板图」。
2. 不满意的镜头：改提示词 → 重新生成；生成过的图都在历史条里可回退。

**第 7 步 · 出视频**
1. 工具栏确认 模型源/模型、时长、比例、分辨率。
2. 点「生成视频」（建议勾选带故事板图作首帧，画面更可控）。
3. 视频生成较慢，可以多镜并行提交后去做别的事——中途关软件也不影响。

**第 8 步 · 精修与导出**
1. 对成片不满意的镜头：换提示词/换垫图重跑；需要更清晰就右击 →「超分」。
2. 镜头之间衔接生硬时用「首帧/尾帧」技巧（见实战五）。
3. 全部满意后逐镜「导出」到本地，进剪辑软件合成整集。

## 实战二：角色造型变体工作流（战损 / 换装）

**场景**：剧情中后期主角要有「战损」形态，出图时不能穿帮变成另一个人。

1. 先把角色的**基础形象定稿**（这是变体的底图，越稳越好）。
2. 角色页该角色卡上点「生成造型变体」，输入变化描述（如「战损：衣衫破损、面部血污」）——AI 会继承基础形象的 DNA，只改变指定项，本质是图生图。
3. 变体图出现在该角色的造型列表里，同样可多次生成、换主图。
4. **在分镜里使用指定造型**：打开资产助手 → 找到该角色 → 右击卡片 → 选中目标造型。之后「提取资产」匹配到该角色时，垫的就是选中的造型图。
5. 该集做完记得把选中造型切回默认，避免下一集误用。

---

## 实战三：图视同源快速出片流（提示词只写一遍）

**场景**：想减少维护两套提示词的工作量，图和视频一体化管理。

1. 视频界面 → 视频设置 → 打开「图视同源」开关，选择同源推理模板（多卡/单卡各选一次即可，随项目记住）。
2. 点「智能推理」：每个分镜只产出**一段**同源提示词，提示词区变成单栏。
3. 修改提示词——只改这一处，出图和出视频都用它。
4. 点「生成故事板图」：系统按提示词里的镜头数**自动追加宫格预设**（≤4 镜→4宫格，5-6 镜→6宫格，更多→9宫格），一张图画出多个镜头。
5. 点「生成视频」：视频用同一段提示词，不带宫格。
6. 同步到画布后结构也不同：同源提示词是独立节点，图片和视频节点并联接它——在画布上改同源节点一处，两路同时生效。

---

## 实战四：画布模式精修一个镜头

**场景**：表格里某个镜头怎么都不对，需要精细控制输入再多方案对比。

1. 视频界面点「同步本集到画布」，切到画布模式——每个分镜是一条「原文 → 故事板 → 视频」流水线。
2. 找到问题镜头的「分镜n原文」节点，单击打开面板，直接改原文；改完点运行 = 单镜重推理，会向下游裂变新的流水线节点。
3. 原文太杂想拆开？右击原文节点 →「拆分…」，按行设置拆分点，一键拆成「分镜n-1、n-2…」多个原文节点，各自独立推理；拆错了多选后右键「重组文本」合回来。
4. 图片节点：右键「匹配资产」补垫图；提示词里插「▦ 预设方案」胶囊；多次生成后按 C 打开堆叠抽屉横向对比，右击最佳一张「设为主图」。
5. 想在正式生成前多试几版：ALT+拖动复制节点，改不同提示词并行跑，好的那版留下。
6. 定稿后右击 →「图像超分」/「超分」提升画质；满意的图右击「绑定到资产…」还能沉淀回资产库复用。

---

## 实战五：镜头衔接技巧（首尾帧续接）

**场景**：相邻两个镜头是连续动作，直接各自生成会跳戏。

1. 先生成上一镜（镜头 A）的视频并定稿。
2. 右击 A 的主视频 → 「尾帧」→ 选择发送到下一镜（镜头 B）。
3. B 的素材区会收到 A 的尾帧图；生成 B 的视频时以它作首帧，动作即可无缝续接。
4. 反向同理：「首帧」可以发给上一镜作参考。画布模式下视频节点悬停工具栏有同款按钮，截出的帧直接生成图片节点，可继续接给任何下游。
5. 需要中间某一段而不是首尾帧时，用「分段」弹窗拖选起止点裁出片段。

---

## 实战六：团队共享素材协作

**场景**：工作室多人做同一 IP，角色形象要全员统一。

**管理者（一次性）**：找服务商开通共享库并拿到库名与加入密码。

**素材提供者**：
1. 把定稿的角色形象做好（实战二）。
2. 右击资产/造型 →「添加到共享资产」→ 选库和文件夹确认。秒完成，不重复上传文件。

**素材使用者**：
1. 资产助手 → 共享资产页 → 搜索库名 + 密码加入。
2. 进入文件夹点「获取」下载素材到本地。
3. 右击共享卡「添加到项目资产…」绑进自己项目（图绑形象、音频绑音色），之后正常走匹配素材流程。

**约定建议**：文件夹按「角色/场景/道具」分开建；素材命名带角色名，方便自动匹配。

---

## 实战七：接入即梦 / LibTV 出视频

**场景**：你有即梦或 LibTV 的会员/额度，想用它们出片，Qiji 侧只花少量手续费。

1. 个人中心 → 对应授权区块 → 点连接，按浏览器提示完成登录授权。
2. 回到视频界面（或画布视频节点），模型源选「即梦」或「LibTV」，旁边再选款式（Seedance 2.0 / Fast / VIP…）。
3. 参数档位会自动切换成该渠道支持的范围（如即梦仅 VIP 款开放 1080p/4K）。
4. 正常垫图、写提示词、生成——垫图、音频参考都会随单发过去。
5. 排队慢是对方平台的常态：超时被打断后点「重连原任务」继续等即可，任务不会丢。

## 附：常用符号与快捷键小抄

**提示词中的符号**
| 符号 | 含义 |
|---|---|
| `@Image1` / `@Video1` / `@Audio1` | 引用素材区第 N 个图/视频/音频（输入 @ 弹候选，数字 1-9 快选） |
| `【素材图例】@Image1 是 xxx` | 匹配素材自动生成的图例行，告诉 AI 每张垫图是谁 |
| `▦ 预设方案` 胶囊 | 提交时展开为完整预设词；双击可展开编辑 |
| `▤ 上游文本N` 胶囊（画布） | 提交时还原为上游节点的文本 |
| `#` | 导入内容到提示词 |

**画布常用快捷键（默认值，均可在设置中改绑）**
| 按键 | 动作 |
|---|---|
| 单击节点 | 选中并打开面板 |
| C | 打开/收起结果堆叠 |
| Ctrl+C / Ctrl+V | 复制 / 粘贴 |
| Ctrl+Shift+C | 全能复制（带上游连线） |
| ALT+拖动 | 拖动复制 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| Ctrl+A / Delete | 全选 / 删除节点、连线 |
| Ctrl+G / Ctrl+Shift+G | 打组 / 解组 |
| Ctrl+Enter | 运行选中节点 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 适配全图 |
| 中键或右键拖动 | 平移画布 |
